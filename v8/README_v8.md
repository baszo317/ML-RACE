# v8：大盤觀點（market view）的診斷與優化

整理日期：2026-10-24。v8 只做研究，**沒有改任何預測**：live 仍用 `v5\daily.bat`，v1–v7 的程式、模型、結果都沒有動。新增兩個工具：監控用的 `monitor_market.py`，和可選用的對沖工具 `hedge_beta.py`（第十一節）。第十二節回答「Transformer + MLP 有沒有用、要不要換 CNN 或 RNN」，第十三節是 LightGBM 和 logistic regression，第十四節是 LSTM、GRU 在大盤和個股，以及全部架構的總表。

## 〇、簡短說明

你看到「大盤預測很糟」，其實是兩個不同的東西加在一起：

1. **明的大盤押注（pbar → 猜 1 的比例）**：pbar 有 57–70% 由「前一天台股」決定（前一天跳空、外資台指期未平倉變化、加權指數報酬），和前一晚美股、夜盤幾乎無關（R² 0.003）。它和當天 Top50 盤中報酬的相關係數：2022–26 平均 0.11，2026/06–10 變成 −0.10。post 期間 timing 的虧損有 76% 來自 15 個極端日。
2. **暗的大盤押注（選股觀點的 beta 傾斜）**：選股觀點長期偏好低 beta 股票（p_e_c > 0 的比例：金融 92% 的 stock-day，半導體 41%，電子 31%）。偏多那一邊平均 beta 約 0.6，偏空那一邊約 1.2（static 上傳檔：猜 1 的平均 beta 0.53，猜 0 的 1.15）。結果是選股分數（xsec）和大盤同向時會輸：xsec 對大盤盤中報酬的斜率 −0.22（相關 −0.38）。大盤盤中漲 100 bp，選股部分平均少 22 bp。

兩者加起來，**每天的總分和大盤盤中漲跌是負相關的（−0.25；2026/06–10 是 −0.43）**：大盤盤中大漲的日子，通常就是我們比較差的日子。這就是「大盤很糟」的感覺來源。

測了 5 個改法（每個都先寫好規則才跑，`research\PREREG_m.md`），**全部沒過門檻**：

| 改法 | val 差（t） | hold 差 | 結論 |
|---|---|---|---|
| T1 選股觀點對 beta 中性化 + 大盤項乘 beta | −1.29（−1.08） | −0.59 | 波動變小，平均也變小 |
| T2 日頻大盤模型（ridge，32 個盤前變數含夜盤）取代 pbar | −0.45（−0.71） | +1.19 | 不比 pbar 好 |
| T3 pbar 和 ridge 平均 | −0.02（−0.04） | +0.67 | 等於沒變 |
| T4 T3 + T1 | −1.68（−1.35） | +0.12 | 變差 |
| T5 選股觀點改用 beta 調整後的殘差重訓 | −0.13（−0.23） | +0.02 | 等於沒變 |

結論：

- **大盤方向本身幾乎不可預測**。盤前能拿到的所有變數（含夜盤、甚至「真正的開盤跳空」）對 Top50 盤中報酬的相關都在 0.1 左右，in-sample R² 只有 1–3%。目前的 pbar 和專門做的日頻模型一樣好。以目前的押注大小，相關每多 0.1 才多約 2 bp/日。
- **最近的糟糕大部分是雜訊**：99 天的相關係數本身就有約 0.10 的抽樣誤差；10 月（15 天）的相關係數抽樣誤差約 0.26，看不出任何東西。
- **不要因為最近大盤很差就關掉或反轉大盤觀點**：timing 的月自我相關是 −0.28（差的月份後面比較常接好的月份）。「過去 60 天 timing 為負就關掉」的規則全期少 0.73 bp/日（t −1.79）。
- 能做的是**風險設定**：beta 傾斜是 w_T 以外的第二個旋鈕，11/23 定版時和 w_T 一起用 live 排行榜決定（第七節）。
- **低 beta 偏好怎麼處理（第十一節）**：不能整個拿掉（完全對大盤中性平均少 3.0 bp/日，val t −2.08）。最好的是「用 beta 比例對沖一半」：每天在 score 加上 c × β_i，讓整本的 beta 曝險抵掉一半的傾斜，每天約改 3 支。walk-forward 平均 13.52 對 13.38（差在雜訊內），每日 sd 49.6 → 44.1，和大盤的相關 −0.25 → −0.07，最大漲 10% 的日子 +1.8 → +17.0、最大跌 10% 的日子 +46.4 → +28.9。λ = 0.5 是看過結果才選的，所以當成 11/23 的風險設定候選。

## 二、架構

| 成員 | 模型 | 輸入 | label | 屬於 |
|---|---|---|---|---|
| mlp_raw_B | MLP（輸入 → 64 → 32 → 1，GELU，dropout 0.2） | B 67 | 收 > 開 | 大盤觀點 |
| mlp_raw_xr | 同上 | B + XR 97 | 收 > 開 | 大盤觀點 |
| tf_raw_B | Transformer encoder（d_model 32、4 heads、2 層、d_ff 64、pre-norm、可學位置向量；每支股票最近 20 天；輸出用最後一天 + 平均） | B 67 | 收 > 開 | 大盤觀點 |
| mlp_res_B | MLP | B 67 | 盤中報酬 > 當天 100 支平均 | 選股觀點 |
| mlp_res_xr | MLP | B + XR 97 | 同上 | 選股觀點 |

- Loss：BCE，權重 = min(|報酬|, 5%)（正規化）。這等於直接最佳化競賽分數 (2p − 1) × 報酬。
- Scaler：只用訓練期，夾在 1% / 99% 分位數再標準化，缺值補 0（訓練平均）。
- 訓練：AdamW（lr 1e-3、wd 1e-2、batch 1024），最多 10 epoch，用訓練期最後 120 天做 early stopping（patience 2），再用全部訓練資料重訓到最佳 epoch。訓練期從 2020-03-02 開始的 expanding window。
- Rolling pool（v4/v5）：每個交易日用到前一天的資料加訓每個 MLP 成員 2 個新 seed，平均最近 5 天（每個成員 10 個模型）；Transformer live 每天 1 個，平均最近 5 個。

## 三、策略（決策規則）

- 大盤觀點：p_raw = (MLP 兩個成員的平均 + Transformer) / 2，pbar = 當天 100 支的平均。
- 選股觀點：p_e = 兩個殘差成員的平均，p_e_c = p_e − 當天平均。
- score = 0.5 × (pbar − 0.5) + p_e_c；score > 0 猜 1。除權息日一律猜 0。
- 防呆（v5 `guards.py`）：資料沒更新、除權息表沒抓到、猜 1 的比例異常就不出檔。
- 分數拆解（`research\mlib.py`、`monitor_market.py`），Top50，s_i = 2d_i − 1，m = Top50 平均盤中報酬，β_i = 個股盤中報酬對 Top100 平均的 120 日滾動 beta（只用 t 以前）：
  - AR = timing + xsec，timing = s̄ × m（明的大盤押注）
  - xsec = beta_bet + rest，beta_bet = B × m，B = mean[(s_i − s̄)(β_i − β̄)]（暗的大盤押注）
  - rest = 和大盤方向無關的選股

### 4.2 pbar 是由什麼組成的（d3、d4）

| 用來解釋 pbar 的變數 | R² |
|---|---|
| 前一天台股：100 支平均跳空、平均盤中報酬、外資台指期未平倉變化（3 個） | 0.570 |

而這些變數和「當天盤中報酬 m」的關係（相關係數，val / hold / post）：

| 變數 | 和 pbar 的相關 | 和 m 的相關 |
|---|---|---|
| txoi_chg（外資期貨 OI 變化） | 0.65 / 0.61 / 0.43 | 0.06 / 0.13 / −0.01 |
| 前一天 100 支平均跳空 | 0.47 / 0.60 / 0.65 | 0.11 / 0.22 / −0.13 |
| twii_ret1 | 0.42 / 0.54 / 0.53 | 0.13 / 0.12 / −0.15 |
| us_gspc_ret1 | −0.05 / 0.00 / 0.04 | −0.04 / −0.07 / −0.22 |
| night_ret（夜盤） | −0.03 / −0.03 / −0.03 | −0.07 / −0.05 / −0.21 |

解讀：pbar 押的是「前一天台股的動能」。這組訊號在 2022–26/05 是對的，在 2026/06–10 翻號，所以大盤觀點在那段失效。前一晚美股和夜盤是四段都同號（負：美股漲，台股隔天盤中偏弱）的訊號，但 pbar 幾乎沒用到。不過它在 val、hold 只有 −0.04 到 −0.07，太弱。

### 4.3 選股觀點的暗押注（d2、e3）

| 年 | 選股觀點偏多（p_e_c > 0）的平均 beta | 偏空（p_e_c ≤ 0） |
|---|---|---|
| 2022 | 0.64 | 1.28 |
| 2023 | 0.55 | 1.32 |
| 2024 | 0.52 | 1.39 |
| 2025 | 0.72 | 1.10 |
| 2026 | 0.61 | 1.09 |

- p_e_c 和 beta 的相關 −0.54；B 平均 −0.30（val −0.35、hold −0.21、post −0.24）。
- 不用 beta 估計的檢查（model-free）：每天的 xsec 對 m 回歸，斜率 −0.22（相關 −0.38；val −0.32、hold −0.09、post −0.18）。也就是選股部分本身帶著約 −0.22 的大盤曝險。
- 每天總分 AR 和 m 的相關：val −0.28、hold −0.08、post −0.43、全期 −0.25（timing 和 m 是 +0.22，xsec 和 m 是 −0.38）。

### 4.4 天花板（e2）

- 就算 9:00 前知道「真正的」開盤跳空（Top50 平均），它和當天盤中報酬的相關也只有 −0.078（val −0.04、hold −0.07、post −0.20），不比夜盤（−0.087）好。扣掉夜盤可以預測的部分後，剩下的跳空和盤中報酬相關 −0.01。所以 8:45 開盤的台指期報價、試撮價都幫不了大盤觀點。

## 八、數學

### 8.1 分數拆解是恆等式

直觀：把每天的分數拆成「整體押多少」、「押哪種 beta 的股票」、「剩下的選股」三塊，三塊加起來一定等於原分數。

證明：Top50 的 s_i = 2d_i − 1，s̄ = 平均，m = 平均報酬。

1. AR = (1/50) Σ s_i r_i = s̄·m + (1/50) Σ (s_i − s̄)(r_i − m)，因為 Σ (s_i − s̄) = 0 和 Σ (r_i − m) = 0，交叉項 (1/50) Σ (s_i − s̄)·m 和 (1/50) Σ s̄ (r_i − m) 都是 0。
2. 令 u_i = r_i − m − (β_i − β̄) m。代入第二項：(1/50) Σ (s_i − s̄)(β_i − β̄) m + (1/50) Σ (s_i − s̄) u_i = B·m + rest。∎

β 是估計值，所以 beta_bet 和 rest 之間的分配會有誤差（4.3 的 10 月就是例子）；AR = timing + xsec 這一步沒有任何誤差。

### 8.2 最佳決策是「每支股票的期望報酬 > 0 就猜 1」

直觀：分數對每支股票是分開、線性的，所以每支股票各自決定，期望報酬是正的就猜 1。

證明：E[AR] = (1/50) Σ (2d_i − 1) E[r_i]。每一項只和自己的 d_i 有關，d_i = 1 時是 E[r_i]，d_i = 0 時是 −E[r_i]，所以 E[r_i] > 0 時選 1 最大。∎

如果 r_i = β_i m + ε_i，E[r_i] = β_i μ + α_i（μ = 大盤期望，α_i = beta 調整後的 alpha）。v4 規則的大盤項對每支股票都一樣（等於假設 β_i 都是 1），而選股觀點學的是 r_i − m，它的期望是 (β_i − 1) μ_歷史 + α_i。T1、T5 就是照這個式子改成 β_i μ + α_i 的版本，結果沒有比較好：在大盤預測這麼弱（μ 幾乎估不出來）的情況下，用不用 β_i 去乘一個接近 0 的東西，差別很小。

### 8.3 大盤押注的天花板

直觀：timing 要賺，曝險要和大盤同方向移動。同方向的程度（相關係數）乘上兩者各自的波動幅度，就是每天平均能賺的上限。

證明：E[s̄ m] = Cov(s̄, m) + E[s̄] E[m]，而 Cov(s̄, m) = ρ σ_s σ_m。σ_s = 0.263、σ_m = 76 bp 時，ρ 每多 0.1，Cov 多 0.1 × 0.263 × 76 ≈ 2.0 bp/日。∎

全期 ρ(s̄, m) = 0.093，Cov 部分 1.87 bp/日，和 d1 表的 timing 拆解一致。

### 8.4 為什麼「最近很差就關掉」會更差

直觀：差的月份後面比較常接好的月份。最近很差就關掉，剛好錯過反彈；最近很好才開，剛好接到回落。

證明：設月 timing X_t 的條件期望是線性的：E[X_t | X_{t−1}] = μ + φ (X_{t−1} − μ)，φ < 0（實測 −0.28）。規則在 X_{t−1} > 0 時開。

1. E[X_t | X_{t−1} > 0] = μ + φ (E[X_{t−1} | X_{t−1} > 0] − μ)。
2. E[X_{t−1} | X_{t−1} > 0] > μ（只要 X 不是永遠大於 0；實測 62% 的月份 > 0）。
3. φ < 0，所以 E[X_t | X_{t−1} > 0] < μ：規則只在「預期低於平均」的月份開。同理，在預期高於平均的月份關掉。∎

### 8.5 相關係數的抽樣誤差約 1/√n

直觀：n 天的相關係數像是 n 個「標準化後的乘積」的平均，每個乘積的變異數約 1，所以平均的標準差約 1/√n。

證明：真實相關為 0 時，標準化後的 x_t、y_t 獨立，Var(x_t y_t) = E[x_t²] E[y_t²] = 1。r ≈ (1/n) Σ x_t y_t，所以 Var(r) ≈ 1/n。∎

n = 15、19、99、250 天時約 0.26、0.23、0.10、0.06。所以 99 天的 −0.10，和長期的 +0.11 差約 2 個標準誤：可能真的變了，也可能只是運氣。10 月的 15 天看不出任何東西。

## 十一、選股觀點的低 beta 偏好：怎麼解決（`research\h6_hedge.py`、`h6_check.py`、`e4_full_neutral.py`）

### 11.1 先看清楚它是什麼

- 一部分是真的 alpha：T5 把 label 換成 r − β·m 重訓，模型還是偏好低 beta（B 只從 −0.30 到 −0.27）。
- 另一部分是押「台股大型股盤中偏跌」：2022–26 大盤盤中平均 −3.2 bp/日，所以這個暗押注長期是賺的（+0.7 到 +1.2 bp/日）。
- 代價是分數跟著大盤反向擺動：v4 在最大跌 10% 的日子平均 +46.4，最大漲 10% 的日子只有 +1.8（中間 80% 的日子 +10.7）。
- 所以目標不是「消滅」它，而是決定要拿多少。

### 11.2 三種對沖方式

整本的 beta 曝險 E = mean_i(s_i β_i) = s̄ × β̄ + B。對沖 = 每天把 E 拉到目標 E*。

- **H6a 用家數對沖**：排序不變，只多猜幾支 1（只看 score，不看 beta）。
- **H6b 用 beta 比例對沖**：score'_i = score_i + c_t × β_i，c_t 選到讓 E 最接近 E*。
- **完全中性**：E* = 0，大盤觀點和暗押注一起拿掉。

事先寫好的測試（`PREREG_m.md` 第三輪）是 E* = s̄_v4 × β̄（拿掉全部的傾斜 B，保留大盤觀點的淨曝險）：

| 設定 | 全期 | val | hold | post | 每日 sd | corr(AR, m) | P(19 天 > 0) | P(> 20) | val 差（t） | hold 差（t） |
|---|---|---|---|---|---|---|---|---|---|---|
| v4（對照） | 13.38 | 13.22 | 13.95 | 12.63 | 49.6 | −0.25 | 0.911 | 0.237 | | |

### 11.4 為什麼用 c × β_i，而不是單純多猜幾支 1

直觀：要把曝險拉高，就得把一些猜 0 的股票改成猜 1。每改一支，會損失模型分數 |score_j|，換到 β_j 的曝險。最划算的是「每單位曝險損失最少」的股票，也就是 |score_j| / β_j 最小的。score + c × β 隨著 c 變大，翻轉的順序剛好就是 |score_j| / β_j 由小到大；單純多猜幾支（H6a）只看 |score_j|，可能翻到 beta 很低、換不到多少曝險的股票。

證明：

1. 問題：在 (1/n) Σ s_i β_i = E* 的限制下，讓 Σ s_i score_i 最大，s_i ∈ {−1, +1}。先放寬成 s_i ∈ [−1, 1]（linear program）。
2. Lagrange 函數：Σ s_i score_i + c (Σ s_i β_i − n E*) = Σ s_i (score_i + c β_i) − c n E*。c 固定時，每一項各自最大化，得到 s_i = sign(score_i + c β_i)。
3. β_i > 0，所以 c 變大時，score_i + c β_i 由負轉正的時點是 c = −score_i / β_i，曝險 Σ s_i β_i 隨 c 單調不減。選 c* 讓限制剛好成立（或最接近），就是放寬問題的最佳解：這是 fractional knapsack 的結構，最多只有一支股票落在 −1 和 1 之間。
4. 把那一支四捨五入成 ±1，目標函數最多差 2 max|score_i|，曝險最多差 2 max β_i / n。翻一支 β ≈ 1 的股票會讓 E 變 2/50 = 0.04，所以實際能做到的 E 和 E* 最多差一半，也就是 `results\h6_check.txt` 裡 |E − E*| 中位數約 0.02 的來源。∎

在 v2 的框架下 score 近似和期望報酬成正比（README_v2 的 5.2），所以這也近似是「曝險固定時期望分數最大」的對沖方式。
