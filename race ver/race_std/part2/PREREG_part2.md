## 4. 命題 5（Top25 加對沖仍然只動 beta 曝險）

設某天 Top50 的決策 s ∈ {±1}^n，β̄ 是平均 beta，曝險 E = mean(s·β) = s̄·β̄ + B，B = mean[(s − s̄)(β − β̄)]。
Top25 時 s̄ = 0（沒有除權息的日子），所以 E = B：Top25 的大盤曝險（以 β 衡量）全部來自選股的 beta 傾斜。

- 直觀：一半看多一半看空，數量抵消了；但如果看多的都是低 beta 股、看空的都是高 beta 股，大盤一漲還是會虧——這就是 B。
  對沖把 B 往 0 拉，λ 決定拉多少。
- 證明：mean(s·β) = mean[(s − s̄ + s̄)(β − β̄ + β̄)] = mean[(s − s̄)(β − β̄)] + s̄·mean(β − β̄) + β̄·mean(s − s̄) + s̄·β̄
  = B + 0 + 0 + s̄β̄。Top25 且沒有除權息時 Σs = 0，s̄ = 0，所以 E = B。∎
