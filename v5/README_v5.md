# v5：以 v4 為基礎的 ablation、feature 去留，以及三個風險的處理

v5 放在 `D:\ML RACE\v5\`，不修改 v1–v4 的任何檔案。整理日期：2026-10-24。

## 〇、簡短說明

架構（和 v4 一樣，預測沒有改）：

- 大盤模型（MLP ×2 + Transformer）：輸出每支股票收盤 > 開盤的機率，100 支平均成 pbar，代表今天大盤會漲的機率。
- 個股模型（MLP ×2）：輸出今天贏過 100 支平均的機率 p_e。用「贏過平均」是為了取相對於大盤。
- 計算分數：0.5 × (pbar − 0.5) + (p_e − 當天平均 p_e) > 0 則為 1；除權息日一律為 0。
- 每個交易日用到前一天為止的資料加訓新模型，平均最近 5 天的模型。

Feature：67 個全部保留。分成 8 組逐組拿掉重訓，沒有一組拿掉後變好；最有用的是個股過去的平均盤中報酬和價量指標。那斯達克和標普的日報酬相關 0.95，一起放進 logistic regression 時係數一正一負，單獨放時方向卻相同，所以是共線性，不是訊號相反；這個模型把那斯達克相關的 6 個全拿掉也沒有變好，所以保留。

Ablation：從 v4 一次拿掉一個元件，全部變差或持平。最確定有用的是除權息規則（t = −3.4）和大盤觀點（t = −2.4）。

三個風險：

- val 重複使用：40 個比較過的設定 PBO = 0.50，分不出好壞；把「挑選」也放進 walk-forward，誠實成績 13.15，比 v2 預設 13.39 低 0.2。測試期的期望值用 12.5–13 bp/日估。
- Concept drift：凍結在 5/29 的 v4 在 6–10 月仍有 12.6 bp/日，和 val、hold 一樣；v1 掉到 0.8 是 v1 規則押太多大盤方向。不過 6–10 月是設計 v2 規則時看過的期間，這個證據不完全乾淨。重訓越新越好（每月比每年多約 1 bp/日），v4 已經每天重訓。
- 檢定力：19 天要差 2–22 bp/日才看得出來，候選改法的差都小於 2.5。能確定的是變異數：每日標準差 58.8 → 46.4，19 天平均 > 0 的機率 0.82 → 0.90。

這次一共測了 21 個改法，都沒過事先定好的門檻（val t ≥ 2、Holm 校正、hold 同號），所以預測不改。v5 只多了每天早上的防呆（資料沒更新、除權息表沒抓到、猜 1 的比例異常就不出檔）和成績監控。

## 一、結論

- **預測本身和 v4 完全相同**：同樣的 5 個成員、同樣的 feature、w_T = 0.5、除權息日猜 0、每天只用到前一個交易日的資料（rolling pool）。
  - 用 v4 的 static 模型重跑 v5，上傳檔 4,200 格全部和 v4 相同。
  - live：用同一批模型（v2 的 10/22 模型）預測 10/23，v5 和 v4 的程式結果完全相同（100 支的 score 差 0）。
- **Feature 去留**：67 個 B 組 feature 和 30 個 rank feature 全部保留（2.2）。67 個分成 8 組，逐組拿掉後重訓，沒有一組拿掉後變好；那斯達克相關的 6 個全部拿掉也一樣。85 個的 F 組（多 18 個外部資料）和 v3 的 5 個新 feature 維持不加（2.3）。
- **為什麼不改預測**：這次一共測了 21 個會改變預測的改法（整夜實驗 7 個、上一輪建議 5 個、拿掉 feature 9 個），全部沒有通過事先定好的採用規則（val 的 paired t ≥ 2，多個一起測時用 Holm 校正，hold 要同號）。在「val 被重複使用」的情況下，硬把沒過關的改法放進去，只會讓 selection bias 更嚴重。
- **v5 實際增加的東西**：
  1. `guards.py`：每天早上的防呆。資料沒併到前一個交易日、除權息表今天沒抓成功、feature 缺值、猜 1 的比例或 pbar 異常時，直接停下，不寫上傳檔。
  2. `monitor_live.py`：把已實現成績拆成 timing、產業押注（between）、產業內選股（within），並和歷史上同樣天數的平均比較，低於 1% 才標出來（誤報率事先算好，6.2）。
  3. 一份事先寫好的決策規則與定版時間表（第六節）。
- 三個風險的診斷結果（第四節）：
  - **Selection bias**：在 40 個實際比較過的設定之間做選擇，PBO = 0.50，也就是「挑 val 最好的」和「隨便挑一個」差不多。但 nested selection（每年只用過去挑）的結果 13.15 和 v2 預設的 13.39 很接近，所以目前設定的 val/hold 數字只有小幅高估。
  - **Concept drift**：凍結在 5/29 的 v4 模型在 6–10 月是 12.63 bp/日，和 val 13.22、hold 13.95 沒有差別；v1 當時掉到 0.76，是因為 v1 規則押太多大盤方向，而不是模型太舊。要注意 6–10 月是設計 v2 規則時看過的期間，所以這只能說明「在看過的資料上，v4 的規則躲掉了 v1 的問題」，不能保證 12 月也一樣。重訓頻率的效果約 +1 bp/日（每月對每年，三段同號，全期 t = 1.71），而 v4 已經每天重訓。
  - **檢定力**：在 19 天的私有測試期，兩個設定的差要大於 2–22 bp/日才看得出來；目前所有候選的差都小於 2.5 bp。唯一看得清楚的是變異數：v2/v4 的每日標準差比 v1 小 21%（Pitman–Morgan t = −13.1），19 天平均 > 0 的機率從 0.82 提高到 0.90。

- 殘差 Transformer 是唯一「明確變差」的選項：val 低 1.19 bp，t = −2.73，hold 也同號。

### 2.2 輸入 feature（67 個 B 組）

**做法**（`research\s11_feature_groups.py`）：

- 把 67 個 B 組 feature 依來源分成 8 組。每次從 4 個 MLP 成員拿掉一組（B+XR 成員也一起拿掉對應的 xr_ rank），用年度 walk-forward 重訓，seed 1–3。Transformer 不變（整夜結果）。
- 另外加一組「那斯達克相關的全部 6 個」：us_nasdaq 加上 us_beta。beta_us 是用那斯達克報酬估的，beta_x_us = beta_us × 那斯達克報酬，所以只拿掉 us_nasdaq 並沒有把那斯達克的資訊完全拿掉。
- 事先寫好的規則：拿掉後 val 要「變好」並通過 Holm（9 組一起測，最好的那組要 t ≥ z(1 − 0.05/9) = 2.54），hold 也要同號，才拿掉；否則保留。

baseline（全部 67 個，MLP seed 1–3）：val 13.41、hold 13.36、post 13.57。

| 拿掉的組（個數） | 內容 | val 差（t） | hold 差（t） | post 差 | 決定 |
|---|---|---|---|---|---|
| us_nasdaq（3） | 那斯達克 1 日、5 日報酬，前一晚的 1 日報酬 | +0.05（0.12） | −0.64（−0.84） | −0.38 | 保留 |
| us_nasdaq + us_beta（6） | 上面 3 個，加上 beta_us 與 beta × 那斯達克 | −0.24（−0.40） | −0.22（−0.27） | −1.77 | 保留 |
| us_other（6） | 標普 1 日、5 日報酬，VIX 與它的變化 | −0.79（−1.82） | −0.80（−1.06） | −1.25 | 保留 |
| us_beta（3） | 個股對那斯達克的 beta 與交互項 | −0.33（−0.70） | −0.62（−0.88） | +0.07 | 保留 |
| tw_market（12） | 加權、KOSPI 報酬，台指期未平倉，前一天大盤與產業的盤中報酬、漲跌家數 | −0.90（−1.46） | +0.16（0.13） | +5.66 | 保留 |
| flows（12） | 外資持股、三大法人買賣超 | −1.28（−2.04） | −0.22（−0.21） | −2.57 | 保留 |

| price_tech（24） | 報酬、K 線形狀、量能、RSI／MACD／布林等技術指標、漲跌停 | −1.91（**−2.90**） | −0.70（−0.56） | −5.10 | 保留 |
| sector（2） | 產業代碼、是否金融 | −0.45（−1.10） | +0.57（0.86） | +0.37 | 保留 |

解讀：

- 沒有一組拿掉後 val 變好到接近門檻（最好的是 us_nasdaq，t = 0.12），67 個全部保留。
- 最有用的是 intra_bias（這支股票習慣開高走低還是開低走高）和 price_tech：拿掉後 val 分別少 2.3、1.9 bp/日（t = −3.7、−2.9），post 也同方向。
- 那斯達克和標普（`research\s12_nasdaq_collinearity.py`）：
  - 兩者日報酬的相關係數是 0.95。用 logistic regression 預測「Top100 平均盤中報酬 > 0」（2020/03–2026/10，1,651 天）：
    - 單獨放：兩者都是負的（美股漲，台股隔天盤中偏弱）。標普 −0.15（z −2.8），那斯達克 −0.11（z −2.3）。
    - 一起放：那斯達克 +0.23（z +1.5），標普 −0.37（z −2.3），方向相反。而且 2025–26 年兩個係數的正負對調。
  - 這是共線性：兩個幾乎相同的變數一起放時，模型實際用的是兩者的「差」，而這個差和台股盤中報酬幾乎無關（相關係數 −0.003）。係數一正一負，不代表兩個市場的訊號相反。
  - 所以在線性模型裡砍掉其中一個，讓係數穩定，是合理的做法。在這裡的 MLP，拿掉與否沒有差別，照規則保留。
- tw_market 拿掉後 post +5.66（t 1.52），但 val −0.90。post 只看一次、不參與決定，這裡只做記錄。

## 四、三個風險：診斷與處理

### 4.1 Validation 被重複使用（selection bias）

**問題**：2022–24 被拿來比較很多次，最後選中的設定，val 分數會偏高。

**診斷 1：CSCV / PBO**（Bailey, Borwein, López de Prado & Zhu, 2017）

- 範圍：開發過程中實際比較過、而且能從存檔預測重建的 40 個設定，2022-01 到 2026-05 共 1,065 天。
- 方法：切成 16 段，所有 C(16, 8) = 12,870 種「一半當 IS、一半當 OOS」的組合，每次挑 IS 最好的設定，看它在 OOS 的排名。
- 結果：PBO = 0.50。IS 最好的設定平均 IS 14.04 bp，到 OOS 只剩 12.26，和 OOS 的中位數設定（12.51）差不多。
- 意義：這 40 個設定在統計上分不出好壞，「挑最好的」和隨便挑一個效果相同（證明見 7.5）。好消息是它們的水準都在 12–14 bp，整體水準不是挑出來的。

**診斷 2：nested selection（把「挑選」本身也放進 walk-forward）**

每年年初，只用之前的年份挑出最好的設定，記錄它在下一年的成績：

| 年份 | 挑到的設定 | 過去 AR | 當年 AR | v2 預設當年 | 40 個設定的中位數 |
|---|---|---|---|---|---|
| 2023 | v2 預設 w_T = 0.75 | 13.97 | 8.91 | 9.80 | 8.25 |
| 2024 | v2 + 4y window | 11.85 | 16.13 | 16.16 | 16.13 |
| 2025 | v2 + 4y window | 13.27 | 11.95 | 11.91 | 10.76 |
| 2026/01–05 | v2 + 4y window | 12.94 | 19.32 | 19.17 | 19.51 |
| 加權平均 | | | **13.15** | **13.39** | 12.63 |

- 「用 val 挑」這個程序本身的誠實成績是 13.15，和 v2 預設差 0.24。所以 selection bias 確實存在，但量級約 0.2–0.8 bp/日，不會改變結論。
- 對私有測試期的期望值，建議用 12.5–13 bp/日，而不是 val/hold 的 13.5。

**診斷 3：多重比較校正（reality check，White 2000；Romano & Wolf 2005）**

- 39 個設定對 v1-like 的 paired t 中，最大值在虛無假設下的 95% 臨界值是 2.73（stationary bootstrap，平均區塊長度 10 天）。
- 只有「v1 + 除權息規則」剛好碰到門檻（t = 2.73，校正後 p = 0.051）。其他設定的 t 都小於 1.8。
- v2/v4 相對 v1 的優勢，在 val + hold 的平均值上沒有通過校正（val +0.92，t 0.73；hold +1.91，t 0.95）。主要差距在 post（+11.9），而 post 正好是設計 v2 時看過的期間。這一點要誠實面對。
- 站得住的是變異數：每日標準差 58.8 → 46.4（比值 0.79），Pitman–Morgan 檢定 t = −13.1（證明見 7.9）。報酬有厚尾和自我相關，常態假設下的 t 會偏大，所以另外用 stationary bootstrap 重抽日子：比值的 95% 區間 0.74–0.85，2,000 次重抽沒有一次 ≥ 1。在平均值差不多的前提下，19 天平均 > 0 的機率從 0.82 提高到 0.90。

**處理**：

- 預測不再依 val/hold 做任何調整，所有候選改法都用同一條事先寫好的規則判斷（第六節）。
- 這次測的候選改法全部沒過，所以 v5 不改預測。
- 從現在到定版（11/23）的 live 成績，是唯一沒被看過的資料。只用來抓錯，不用來調參。

### 4.2 Concept drift

**問題**：v1 在 6–8 月只有 2.72 bp/日；2026/01–05「全部猜 0」有 15.5。

**診斷 1：先確認說法**

- 「2026/01–05 全部猜 0 勝過所有模型」不精確：v1 的 transformer_B（13.93）輸給它，但 v1 ensemble_B（17.82）、v2 預設（19.17）、v4 規則都贏。

## 七、數學說明

### 7.1 timing = skill + drift

**直觀**：猜 1 比較多的日子如果剛好是大盤漲的日子，賺的是判斷力（skill）；如果只是平均偏多或偏空，而大盤的平均剛好同方向，賺的是「漂移會延續」這個賭注（drift）。漂移反轉時，只有前者留得住。

**證明**：令 s_t = 當天 Top50 的淨曝險（猜 1 的比例 × 2 − 1），m_t = 當天 Top50 的平均盤中報酬，timing_t = s_t·m_t，共 n 天，s̄、m̄ 為平均。

1. 展開 (s_t − s̄)(m_t − m̄) = s_t m_t − s̄ m_t − s_t m̄ + s̄ m̄。
2. 對 t 取平均：(1/n)Σ(s_t − s̄)(m_t − m̄) = (1/n)Σ s_t m_t − s̄ m̄ − s̄ m̄ + s̄ m̄ = (1/n)Σ s_t m_t − s̄ m̄。
3. 移項：(1/n)Σ s_t m_t = cov(s, m) + s̄·m̄，其中 cov 是以 1/n 計算的共變異數。∎

### 7.2 選股 = 產業之間 + 產業之內

**直觀**：選股賺的錢可能來自「押對產業」（金融整體贏過電子），也可能來自「在同產業裡挑對股票」。前者其實是幾個產業價差的賭注，波動比較大，產業輪動時會一起虧。

**證明**：某一天的 Top50 共 N 支，s_i ∈ {−1, +1}，r_i 為盤中報酬。產業 g 有 n_g 支，w_g = n_g/N，s_g、r_g 為產業內平均，s̄、r̄ 為全體平均。

1. AR = (1/N)Σ s_i r_i，timing = s̄ r̄，所以 xsec = AR − timing = (1/N)Σ(s_i − s̄)(r_i − r̄)（同 7.1 第 1–3 步）。
2. 拆開 s_i − s̄ = (s_g − s̄) + (s_i − s_g)，r_i − r̄ = (r_g − r̄) + (r_i − r_g)，g = g(i)。
3. 在同一產業內加總四個乘積：
   - Σ_{i∈g}(s_g − s̄)(r_g − r̄) = n_g(s_g − s̄)(r_g − r̄)。
   - Σ_{i∈g}(s_g − s̄)(r_i − r_g) = (s_g − s̄)·Σ_{i∈g}(r_i − r_g) = 0，因為產業內偏差加總為 0。
   - 同理 Σ_{i∈g}(s_i − s_g)(r_g − r̄) = 0。
   - 剩下 Σ_{i∈g}(s_i − s_g)(r_i − r_g)。
4. 對所有產業加總再除以 N：xsec = Σ_g w_g(s_g − s̄)(r_g − r̄) + (1/N)Σ_i(s_i − s_g(i))(r_i − r_g(i))。前者是 between，後者是 within。∎

### 7.3 最小可偵測效果（MDE）

**直觀**：n 天的平均差有雜訊 σ_d/√n。真正的差要比雜訊大好幾倍，檢定才有足夠的機會把它抓出來。

**證明**：設 d_1, …, d_n 獨立，平均 μ，標準差 σ_d。檢定 H0: μ = 0，當 d̄ /(σ_d/√n) > z_{1−α/2} 時拒絕（考慮 μ > 0 這一側）。

1. 在真實平均為 μ 時，d̄ ≈ N(μ, σ_d²/n)，所以 Z = (d̄ − μ)/(σ_d/√n) ≈ N(0, 1)。
2. 檢定力 = P(d̄/(σ_d/√n) > z_{1−α/2}) = P(Z > z_{1−α/2} − μ√n/σ_d) = Φ(μ√n/σ_d − z_{1−α/2})。
3. 要求檢定力 = 1 − β：μ√n/σ_d − z_{1−α/2} = z_{1−β}，得 μ = (z_{1−α/2} + z_{1−β})·σ_d/√n。
4. α = 0.05、β = 0.2 時係數為 1.96 + 0.84 = 2.80。∎

### 7.4 長期較好的設定，在 n 天內也勝出的機率

由 7.3 第 1 步，d̄ ≈ N(μ, σ_d²/n)，所以 P(d̄ > 0) = P(Z > −μ√n/σ_d) = Φ(μ√n/σ_d)。代入 n = 19、μ = 長期平均差，就是第 4.3 節表格的最後一欄（取兩方中較大者）。單一設定 19 天平均 > 0 的機率同理是 Φ(μ√19/σ)。∎

### 7.5 設定之間分不出好壞時，PBO = 1/2

**直觀**：如果每個設定的真實水準都一樣，IS 表現最好的那個只是運氣最好，換到 OOS 時運氣重抽，它的排名就和隨便抽一個一樣。

**證明**：設 N 個設定的每日分數，在「交換設定編號」下聯合分布不變（exchangeable），且 IS 和 OOS 的日子互相獨立。

1. IS 最好的編號 n* 只由 IS 資料決定，所以 n* 與 OOS 的表現向量 (O_1, …, O_N) 獨立。
2. (O_1, …, O_N) 可交換：任何一個固定編號 k，O_k 在 N 個值中的排名都是 {1, …, N} 上的均勻分布（假設沒有同分）。
3. 由 1，給定 n* = k 時，O_{n*} 的排名分布等於 O_k 的排名分布，也是均勻分布。
4. 所以 P(O_{n*} 的排名不高於中位數) = 1/2，即 PBO = 1/2。∎

PBO 明顯小於 1/2，才表示 IS 的贏家在 OOS 也比較會贏，也就是「挑選」有用。

### 7.6 max-t 控制「至少一個誤判」的機率

**直觀**：同時比較 K 個設定時，即使全部都沒有比 baseline 好，最大的 t 值也會隨 K 變大（K 個獨立標準常態的最大值約 √(2 ln K)，K = 39 時約 2.7）。所以門檻要用「最大值」的分布，而不是單一 t 值的 1.96。

**證明**：在完全虛無假設下（所有 μ_k = 0），令 c 為 max_k T_k 的 1 − α 分位數。

1. 事件「至少一個 T_k ≥ c」等於事件「max_k T_k ≥ c」。
2. 所以 P(至少一個誤判) = P(max_k T_k ≥ c) = α。∎

實作上，max_k T_k 的虛無分布用 stationary bootstrap 估計：每個設定的每日差先減去自己的平均（讓虛無假設成立），再以平均長度 10 天的隨機區塊重抽日子，保留自我相關與設定之間的相關（Politis & Romano, 1994）。

### 7.7 Holm 校正

把 K 個 p 值由小到大排成 p_(1) ≤ … ≤ p_(K)，從最小的開始，只要 p_(j) ≤ α/(K − j + 1) 就拒絕並往下走，否則停止。

**證明（至少一個誤判的機率 ≤ α）**：令 I₀ 是真的虛無假設的集合，大小 K₀。

1. 假設發生了至少一個誤判，令 j 為第一個被拒絕的真虛無假設的排序位置。
2. 在第 j 步之前被拒絕的都是假的虛無假設，最多 K − K₀ 個，所以 j ≤ K − K₀ + 1，門檻 α/(K − j + 1) ≤ α/K₀。
3. 所以「至少一個誤判」⊆「min_{i∈I₀} p_i ≤ α/K₀」。
4. 由 union bound，P(min_{i∈I₀} p_i ≤ α/K₀) ≤ Σ_{i∈I₀} P(p_i ≤ α/K₀) = K₀·α/K₀ = α。∎

### 7.8 為什麼用斜率檢查 bp 規則的理論

README_v2 5.1 證明了 E[e | x] = (2p_e − 1)·E[|e| | x]。若 E[|e| | x] = c·ε̂（c 為常數），則在 ε̂ 相近的一組股票日裡，e 對 (2p_e − 1) 過原點迴歸的斜率約為 b_X·c·mean(ε̂)，b_X 是共同的 attenuation。所以斜率應該和該組的 mean(ε̂) 成正比，斜率比應等於 ε̂ 比（3.13）。實測 2.05，換成彈性約 log 2.05 / log 3.13 = 0.63：大波動股票的機率偏差確實值比較多 bp，但沒有理論說的那麼多，所以照理論放大反而過頭。

### 7.9 Pitman–Morgan：同一批日子的兩個變異數怎麼比

**證明**：Cov(X + Y, X − Y) = Var X − Cov(X, Y) + Cov(Y, X) − Var Y = Var X − Var Y。所以 Var X = Var Y 等價於 X + Y 與 X − Y 不相關。在二元常態下，相關係數 r 的檢定統計量 t = r√(n − 2)/√(1 − r²) 服從自由度 n − 2 的 t 分布。∎

這個檢定使用同一天的配對，所以兩個設定共有的大盤雜訊會互相抵銷，檢定力比比較平均值高很多。
