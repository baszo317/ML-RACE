# live 排行榜紀錄

11/23 定版時要決定大盤權重 w_T 和 beta 對沖比例（`v7\README_v7.md` 第三節、`v8\README_v8.md` 第七節）。這個決定要用 10/12–11/20 **各隊每天的分數**：各隊的平均、波動，以及和大盤的相關。daily board 如果只顯示當天，沒記下來的日子之後就拿不回來，所以每天記一次。

## 每天做的事（大約 1 分鐘）

1. daily board 和 accumulated board 各截一張圖，存在這個資料夾，檔名用日期：
   - `20261027_daily.png`
   - `20261027_accum.png`
2. 有空的話，把分數抄進 `daily_board.csv`（一隊一個 row）：

   | column | 內容 |
   |---|---|
   | date | 分數所屬的交易日，例如 2026-10-27 |
   | rank | 當天名次 |
   | team | 隊名（每天寫法要一致） |
   | daily_score | 當天分數（排行榜上的原始數字，例如 0.001913） |
   | accum_score | 累積分數 |
   | note | 備註（例如這天我們沒上傳） |

只有截圖也可以：11/20 左右把截圖給我，我再整理成表。
