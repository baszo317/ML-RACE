## 0. 結論

overfit 在這個專案有三種意思，答案不一樣：

| 層次 | 會不會 | 會不會讓看到的分數變假 | 主要證據 |
|---|---|---|---|
| A. 模型權重在訓練期上學到雜訊 | 會，而且很明顯 | **不會**：所有分數都是 walk-forward 樣本外，理論上無偏（定理 1） | 成員在自己訓練期上的 IC / 相關是樣本外的 1.5–4 倍；迷你流程樣本內 AR 27.4、樣本外 13.7。用純雜訊 label 訓練，樣本內也做得到相近的數字（3.1 節）。early stopping 停在樣本外 loss 最低附近 |
| B. 在同一段歷史上比很多設定、再挑最好的 | **會，這是這個專案真正 overfit 的地方** | 會：挑出來的「進步」大多是雜訊 | 65 個篩選過的改法，val 和 hold 的相關 0.16；照 val > 0 入選的 32 個，hold 平均 −0.003；v11 − v9 真正的效果估計約 +0.04 到 +0.2 bp/日（3.2 節） |
| C. 用最近一小段（static、10 月）挑係數 | 風險最高 | 會 | 99 天上「最好的一組比 v9 多多少」的純運氣上限 29–36 bp/日；歷史上用前 99 天挑 4,375 組裡最好的、用在下 19 天：平均比 v9 少 2.73 bp/日（t −2.86，56 次裡 73% 輸）（3.2 節） |

- **核心的 edge 是真的，不是 overfit 出來的。** v11 15.02 bp/日（t 11.1）、v9 14.31（t 10.6）、W0 12.22（t 10.7）。有限樣本的 Bernstein 下界（把每天的條件標準差假設到實際的 2 倍）仍是 +3.3、+2.6、+1.7；把試過的設定數算成 10 萬組，Deflated Sharpe Ratio 仍是 1.00（定理 2、3.2 節）。
- **v5 → v9 → v11 疊上去的改進，分不出是不是真的。** v9 − v5 +0.93（t 1.68）、v11 − v9 +0.71（t 1.19），都在「從 7–26 個候選裡挑最好的」純雜訊會出現的範圍內。hold、post 已經被拿來做過至少 20 次通過 / 不通過的決定，照定理 4，現在 hold 只能確認大於約 2.3 bp/日（單一改法）或 5.8 bp/日（v11 對 v9）的差。
- **W0 是 C 的情形。** 它的係數最早是在 static 上挑的（v9 第八節、v11 第 7 節），10 月又看起來很好（10 月 W0 − v11 +14.3，t 3.2）。但 240 組裡最好的一組，在純雜訊下 max t 的期望就約 2.8。同樣的係數放在 v9 的 4,375 組格子裡，val 排第 3,672、hold 第 3,557，post 卻排第 31：這是 regime 的排名，不是穩定的好。五年 walk-forward W0 比 v11 少 2.80 bp/日（t −2.52）；歷史上「這組係數前 99 天贏 v9」之後的 19 天，它平均再輸 v9 5.58。W0 真正的好處是波動小（sd 38.4 對 48.0），19 天平均 > 0 的機率兩者都約 0.90。所以 W0 是風險選項，不是期望分數比較高的選項（和 v11 第 6、7 節相同，這次多了理論上界和 CSCV）。
- **時間上的漂移目前看不出來。** 10 個半年的真實水準只在約 ±2 bp/日內移動（random-effects τ：v9 2.2、v11 1.8、W0 0.3；Q 9–12，自由度 9）。選股每一個 fold 的 IC 都是正的（0.07–0.13）；大盤觀點在 2026-06 以後轉負（相關 −0.03 到 −0.15），這是唯一看得到的 regime 變化。
- **私有測試期約 19 天**：含漂移的預測區間 v11 約 −7 到 +35 bp/日，P(平均 > 0) ≈ 0.90；v9 −8 到 +35（0.89）；W0 −6 到 +29（0.90）。10/27 live 的 −70 到 −84 是每個設定歷史上 1–2% 的壞日子，一天說明不了 overfit。

## 1. 符號

- 第 t 天（t = 1, …, n）的決策 d_t（50 支 0/1），s_{t,i} = 2 d_{t,i} − 1；r_{t,i} = 盤中報酬。
- 當天分數 X_t = (1/50) Σ_i s_{t,i} r_{t,i}（AR）。
- F_{t−1}：第 t 天 09:00 前拿得到的全部資訊（含到第 t−1 天收盤的 label）。
- **沒有 look-ahead**：d_t 只由 F_{t−1} 決定（數學上叫 F_{t−1}-measurable）。之前的檢查：把資料截到 D 之前再預測，機率差約 1e-8（transformer README）；`v6\leak_check.py`；v9 上線程式和研究版逐日相同。
- μ_t = E[X_t | F_{t−1}]：用當天實際做的決策，在當天條件下的期望分數，也就是「真正的 skill」。
- walk-forward 平均 X̄ = (1/n) Σ X_t；我們想知道的是 μ̄ = (1/n) Σ μ_t。

## 2. 理論保證

一句話版本：**沒有任何定理能保證「不會 overfit」**；能保證的是（1）walk-forward 的數字不會因為模型 overfit 而虛高、（2）它離真正的 skill 多遠、（3）挑選和重複使用資料會讓它高估多少。對未來還需要一個「漂移不大」的假設，這一點沒有定理能免除。

### 定理 0：為什麼訓練期（樣本內）的成績一定高估

**敘述**：固定 feature x_i，r_i = f_i + e_i，E[e_i | x] = 0。s_i 是用「包含 r_i 的資料」訓練出來的決策（樣本內），r'_i = f_i + e'_i 是同一個 x_i 下另一個獨立的新結果。則

E[s_i r_i] − E[s_i r'_i] = Cov(s_i, e_i)。

**直觀**：樣本內的決策「看過」自己要被評分的那個雜訊 e_i，會順著它走，多出來的分數就是 s_i 和 e_i 的共變異。模型越能記（參數越多、訓練越久），這一項越大。3.1 節的隨機 label 實驗量的就是這一項：label 只有 e，沒有 f。

**證明**：
1. e'_i 和訓練資料獨立、平均 0，所以 E[s_i e'_i] = E[s_i] E[e'_i] = 0，E[s_i r'_i] = E[s_i] f_i。
2. E[s_i r_i] = E[s_i] f_i + E[s_i e_i]，而 E[e_i] = 0，所以 E[s_i e_i] = Cov(s_i, e_i)。
3. 兩式相減。∎

（這是 Efron 的 covariance penalty 用在這個分數上的版本。）

### 定理 1：walk-forward 的平均不會因為 overfit 而虛高

**敘述**：若每個 d_t 只由 F_{t−1} 決定，則 M_n = Σ_{t≤n} (X_t − μ_t) 是 martingale，而且 E[X̄] = E[μ̄]。

**直觀**：決策在當天收盤前就定了，當天的雜訊不可能「被它順著走」，定理 0 的 Cov 項變成 0。模型 overfit 只會讓 μ_t 變小（決策變差），walk-forward 會老實地量到變差，不會把它量成變好。

**證明**：
1. μ_t 由 F_{t−1} 決定，所以 E[X_t − μ_t | F_{t−1}] = E[X_t | F_{t−1}] − μ_t = 0。
2. 因此 E[M_n | F_{n−1}] = M_{n−1} + E[X_n − μ_n | F_{n−1}] = M_{n−1}：M_n 是 martingale（|X_t| ≤ 22.2%，期望值都存在）。
3. 逐層取期望（tower property）：E[M_n] = E[M_{n−1}] = … = 0，也就是 E[X̄ − μ̄] = 0。∎

**兩個前提**：沒有 look-ahead（第 1 節的檢查）；以及「同一段資料只評估一個事先定好的程序」。在同一段資料上比較很多程序再挑最好的，挑出來的那個就不再無偏（定理 3）。

### 定理 2：有限樣本下，walk-forward 離真正的 skill 最多多遠（Bernstein / Freedman）

**敘述**：若 X_t − μ_t ≤ R，而且每一天的條件變異數 Var(X_t | F_{t−1}) ≤ σ²，則對 a > 0：

P( Σ (X_t − μ_t) ≥ a ) ≤ exp( −a² / (2 (nσ² + R a / 3)) )。

所以機率至少 1 − δ：μ̄ ≥ X̄ − ε，ε = [ L R/3 + √( (L R/3)² + 2 L n σ² ) ] / n，L = ln(1/δ)。

**直觀**：每天的「運氣」X_t − μ_t 平均是 0，n 天加起來會互相抵銷，抵銷的速度由變異數 σ² 決定；R 只是防止極端的單日把界拉壞的修正項。只用範圍（Hoeffding）會被 ±22% 的漲跌停範圍拖垮，用變異數才有意義。

**證明**：令 Y_t = X_t − μ_t，E[Y_t | F_{t−1}] = 0，E[Y_t² | F_{t−1}] ≤ σ²，Y_t ≤ R。
1. 令 g(u) = (e^u − 1 − u)/u²（g(0) = 1/2）。由 Taylor 積分餘項，e^u − 1 − u = u² ∫₀¹ (1 − s) e^{us} ds，所以 g(u) = ∫₀¹ (1 − s) e^{us} ds，對 u 遞增。
2. 對 λ > 0、y ≤ R：e^{λy} = 1 + λy + (λy)² g(λy) ≤ 1 + λy + λ² y² g(λR)（g 遞增、λy ≤ λR）。
3. 取條件期望：E[e^{λY_t} | F_{t−1}] ≤ 1 + λ² σ² g(λR) ≤ exp(λ² σ² g(λR))。
4. 逐天用 tower property：E[e^{λ M_n}] = E[ e^{λ M_{n−1}} E[e^{λ Y_n} | F_{n−1}] ] ≤ exp(λ²σ² g(λR)) E[e^{λ M_{n−1}}] ≤ … ≤ exp(n λ² σ² g(λR))。
5. Markov 不等式：P(M_n ≥ a) ≤ e^{−λa} E[e^{λ M_n}] ≤ exp(−λa + n λ² σ² g(λR))。
6. 對 0 ≤ u < 3：g(u) = Σ_{k≥2} u^{k−2}/k! ≤ (1/2) Σ_{j≥0} (u/3)^j = 1/(2(1 − u/3))，因為 k! ≥ 2·3^{k−2}（k = 2 等號；之後每多一項左邊乘 k + 1 ≥ 3）。
7. 取 λ = a/(nσ² + Ra/3)（這時 λR < 3），則 1 − λR/3 = nσ²/(nσ² + Ra/3)，代入 5、6：
   −λa + nλ²σ²/(2(1 − λR/3)) = −a²/(nσ² + Ra/3) + a²/(2(nσ² + Ra/3)) = −a²/(2(nσ² + Ra/3))。
8. 令右邊 = δ，解 a² − (2LR/3) a − 2Lnσ² = 0 的正根，得到 ε = a/n。∎

**數字**（`results\o5_bounds.txt`，δ = 0.05 單尾）：漲跌停 ±10%，開盤、收盤都在前一天收盤的 ±10% 內，所以 |r| ≤ 1.1/0.9 − 1 = 22.2%，|X_t| ≤ 2,222 bp，R = 4,444 bp。n = 1,164。

|---|---|---|---|---|---|---|
| v11 | 15.02 | ≥ 6.07 | ≥ 4.78 | ≥ 3.33 | ≥ 12.79 | 159 |
| v9 | 14.31 | ≥ 5.35 | ≥ 4.06 | ≥ 2.59 | ≥ 12.10 | 159 |

- 全期的 skill 是正的，這一點在很保守的假設下都成立。σ 是對「每天條件變異數」的假設（報酬有厚尾，所以另外放大到 1.5、2 倍）。
- 單看一段就不行了：hold（338 天）、post（99 天）、10 月（15 天）的有限樣本下界都是負的；漸近的下界 hold、post 仍是正的（v11 10.1、10.1），10 月 v11 是 −8.0。也就是 **15 天的成績在理論上什麼都證明不了**。

### 定理 3：挑選會高估多少（在 K 個裡挑最好的）

**敘述**：K 個程序在同一批日子上評估，Z_k = X̄_k − μ̄_k，挑 k̂ = argmax_k X̄_k。
- (a) E[X̄_{k̂} − μ̄_{k̂}] ≤ E[max_k Z_k]。
- (b) 若每個 Z_k 都是 sub-Gaussian（E[e^{λ Z_k}] ≤ e^{λ² s²/2}；例如由 martingale CLT 近似成平均 0、標準差 ≤ s 的常態），則 **不管 Z_k 之間怎麼相關**，E[max_k Z_k] ≤ s √(2 ln K)。
- (c) 機率至少 1 − δ：所有 k 同時 |Z_k| ≤ ε_K = s √(2 ln(2K/δ))；這時報出來的分數最多高估 ε_K，挑到的那個比真正最好的最多差 2ε_K。

**直觀**：每一組設定的歷史成績 = 真正的好 + 運氣。挑最好的，挑到的多半是「真的好一點又剛好運氣好」的那組，報出來的分數會把運氣算進去。候選越多，最大的運氣越大，但只以 √(ln K) 的速度長：所以真正的問題是 s（期間短 → s 大）。

**證明**：
- (a) 逐點：X̄_{k̂} − μ̄_{k̂} = Z_{k̂} ≤ max_k Z_k，取期望。
- (b) 對 λ > 0，由 Jensen：exp(λ E[max_k Z_k]) ≤ E[exp(λ max_k Z_k)] = E[max_k e^{λ Z_k}] ≤ Σ_k E[e^{λ Z_k}] ≤ K e^{λ² s²/2}。取 log：E[max_k Z_k] ≤ (ln K)/λ + λ s²/2；取 λ = √(2 ln K)/s 得 s √(2 ln K)。這一步只用到加總，所以和相關結構無關。
- (c) sub-Gaussian 的尾巴 P(|Z_k| > ε) ≤ 2 e^{−ε²/(2s²)}；K 個加起來 = δ 解出 ε_K。在這個事件上，令 k* 是真正最好的：μ̄_{k̂} ≥ X̄_{k̂} − ε_K ≥ X̄_{k*} − ε_K ≥ μ̄_{k*} − 2ε_K。∎

用在「和 v9 的差」：Z_k = (X̄_k − X̄_0) − (μ̄_k − μ̄_0)。照差來挑和照分數來挑是同一件事，而差的標準誤 s 小很多（大盤共同的雜訊抵掉了）。

### 定理 4：hold、post 被重複使用之後，還能確認多小的差

**敘述**：設 hold（或 post）只透過 b 次「通過 / 不通過」影響最後選哪個程序（決策紀錄 τ ∈ {0,1}^b），最後的程序 k̂ = k(V, τ)，V 是 val 和更早的資料。若每個固定程序在 hold 上的 Z^H_k 是 sub-Gaussian（標準差 ≤ s），則機率至少 1 − δ：

|X̄^H_{k̂} − μ̄^H_{k̂}| ≤ s √( 2 ( b ln 2 + ln(2/δ) ) )。

**直觀**：每用 hold 做一次決定，就從 hold 拿走最多 1 bit 的資訊；b 個 bit 等於在 2^b 個候選裡挑，定理 3 的 ln K 變成 b ln 2。hold 不會一用就「髒掉」，但能確認的差會越來越大。

**證明**：
1. 給定 V，可能的最後程序是集合 K_V = { k(V, τ) : τ ∈ {0,1}^b }，最多 2^b 個，而且這個集合在看到 hold 之前就固定了（只和 V、以及事先的決策規則有關）。
2. 對 K_V 裡每一個固定的 k：P(|Z^H_k| > ε | V) ≤ 2 e^{−ε²/(2s²)}。
3. union bound：P( max_{k ∈ K_V} |Z^H_k| > ε | V ) ≤ 2^b · 2 e^{−ε²/(2s²)}；令它 = δ，得 ε = s √(2(b ln 2 + ln(2/δ)))。
4. k̂ ∈ K_V，所以 |Z^H_{k̂}| ≤ max_{k ∈ K_V} |Z^H_k| ≤ ε。∎

**b 有多大**：照各版 README，用 hold、post 做過的通過 / 不通過至少有：v7 的 3–4 項、v8 的 5–10 項、v9、v9 第十一節（自動調整）、v10、v11 第一、二部分、X5、v12、F1、F2，以及 static 上傳（w 0.25）和 10/27 上傳 W0 的決定；README 的表格裡還有很多「看過」的 hold、post 數字（這些也算資訊）。所以 b ≥ 20 是保守的。

### 定理 5：對未來（私有測試期）要多一個假設

**敘述**：令 μ_F 是未來那一段的平均 skill。則 μ_F = μ̄ + Δ，Δ 是漂移；過去的資料無法在沒有假設的情況下限制 Δ。若假設各段的真實水準 μ_h 是平均 m、標準差 τ 的隨機效果（random effects），新的一段 19 天的平均 X̄_F 滿足

E[X̄_F] = m，Var(X̄_F) = τ² + s₁₉² + se(m̂)²，

s₁₉ 是 19 天平均的抽樣標準差（含序列相關），se(m̂) 是 m 的估計誤差。

**直觀**：未來的平均 = 長期水準 + 這一段水準的偏離（漂移）+ 這 19 天的運氣。前兩者用過去 10 個半年估計；運氣來自定理 2 的那種雜訊。

**證明**：X̄_F − m̂ = (μ_F − m) + (X̄_F − μ_F) − (m̂ − m)。第一項變異數 τ²；第二項是未來那 19 天的 martingale 平均（定理 1），條件在 μ_F 下平均 0、變異數 s₁₉²，所以和第一項不相關；第三項只用過去資料，和未來兩項獨立。三項變異數相加。∎

τ 用 DerSimonian–Laird 估計（Q = Σ w_h (y_h − ȳ)²，τ² = max(0, (Q − (k−1)) / (Σw − Σw²/Σw))，w_h = 1/se_h²）。數字見 3.3 節。

### 附註：為什麼不用 VC / Rademacher 這類「容量」上界

這類定理保證「訓練錯誤率和真正錯誤率的差」不超過某個和模型容量有關的量，但需要獨立同分佈的樣本。代入這裡（`results\o5_bounds.txt`）：

- 67 個 feature 的線性規則（VC 維度 68），樂觀地把 15.3 萬個 stock-day 當成獨立：差距上界 0.184（錯誤率），而模型樣本外的 edge 只有 0.04–0.06。
- 大盤觀點實際上是從「天」學（約 1,530 天），同一個線性規則的上界變成 1.32；MLP（約 6,800 個權重）上界 > 1。

全部都比要證明的效果大，沒有用（vacuous）。所以這個專案用的是樣本外的保證（定理 1–4），它們不依賴模型多複雜，只依賴「評估的資料沒有被拿去訓練或挑選」。

## 3. 實驗數據

### 3.1 模型權重：訓練期 vs 樣本外、learning curve、純雜訊 label（`research\o1_gap.py` → `results\o1_gap.txt`）

做法：三個成員照 walk-forward 原樣重訓（年度 fold 2022 到 2026-05 + post，訓練期 2020-03-02 到 fold 前一天，最後 120 天 early stopping，再用整段 refit），真的 label seed 1–3、隨機 label seed 1：

- mlp_raw_B9（大盤觀點 MLP）、mlp_res_xr9（選股 MLP）：torch 在雲端裝不起來，所以用 `research\npmlp.py` 以 numpy 重寫同一個模型和訓練程序（同樣的層、GELU、dropout、AdamW、clip、batch、early stopping、refit；不是逐位相同）。
- lgb_res（選股 LightGBM）：真的 lightgbm 4.7.0、同樣參數。
- 檢查是不是同一個模型（樣本外預測和快取的 walk-forward 比）：預測相關 0.974、0.984、0.998；樣本外指標 0.089 對 0.106（corr(pbar, m)）、0.104 對 0.106（IC）、0.1048 對 0.1050（IC）。

- 雜訊 label 的樣本外都約等於 0：迷你流程 1.94 bp/日（se 1.09；拿掉除權息規則 1.39），在雜訊內。除權息規則不是學出來的，所以拿掉它更接近 0。這也是定理 1 的實驗版：學不到東西時，walk-forward 不會憑空變好。

| mlp_raw_B9 | corr 0.31 → 0.60（epoch 1 → 10），log-loss 一直降 | corr 0.08–0.11 持平；log-loss 從 epoch 1 起就一直變差（0.6935 → 0.7082） | 1.5 個 epoch：接近樣本外 log-loss 最低 |

| 2023 | 0.050 | 0.037 | 0.104 | 0.100 |
| 2024 | 0.150 | 0.148 | 0.129 | 0.127 |
| 2025 | 0.177 | 0.192 | 0.098 | 0.100 |

選股每一段都是正的而且穩定；大盤觀點在 2026-06 以後翻負（和 v8 第 4.2 節「pbar 押的是前一天台股的動能，2026/06–10 翻號」、v11 第 7 節看到的 regime 一致）。Transformer 和 MLP 的樣本外行為一樣；它的訓練期差距這次沒有量（沒有 torch），但它參數更多、看 20 天的序列，記憶能力只會更大，early stopping（patience 2）同樣是唯一的保護。

### 3.2 選擇：CSCV、reality check、短期挑係數、改法的 winner's curse（`o2_selection.py`、`o3_shrinkage.py`）

**CSCV / PBO**（Bailey, Borwein, López de Prado & Zhu 2017）：1,164 天切成 16 段，12,870 種「一半當樣本內、一半當樣本外」的切法；每次挑樣本內最好的設定，看它在樣本外的排名。PBO = 它落在樣本外後半的比例。所有設定一樣好時 PBO = 0.5（v5 7.5 的證明）；挑選有用時 PBO 接近 0。

| 候選 | 個數 | PBO | 樣本內最好的：樣本內 → 樣本外 | 樣本外中位數 | 和 v9 的係數比（同一半） |
|---|---|---|---|---|---|
| v9 的係數格子（w_T、λ、lgb_w、tf_w、bias） | 4,375 | 0.43 | 15.45 → 12.77 | 12.83 | −1.54，只有 2.1% 的切法贏 |
| 只動 w_T、λ（W0 在裡面） | 35 | 0.14 | 14.68 → 13.96 | 13.10 | −0.35，53% 贏 |
| 開發過的所有版本與變體（v5–v12、Alpha158、ablation） | 92 | 0.46 | 15.50 → 14.36 | 14.28 | +0.05，51% 贏 |

- 格子越大，挑選越沒用：4,375 組裡挑出來的，樣本外和隨便一組一樣（12.77 對 12.83），而且 98% 的切法輸給直接用 v9 的係數。樣本內和樣本外的斜率是負的（−0.92）：樣本內越好看，樣本外越差。這就是定理 3 的「挑到運氣」。
- 只動 w_T、λ 的 35 組，挑選還有一點用（PBO 0.14），但挑到的四分之三是 w_T 0.5（λ 1.0 或 v9 的 0.75）；W0（w_T 0、λ 0.5）在 12,870 次裡只被挑中 26 次，樣本外平均排名 0.32（後半），v9 是 0.88。
- 92 個開發過的版本之間分不出好壞（PBO 0.46）：v5 到 v12 的差別，在同一段歷史上就是雜訊大小。
- 改 S（切成 8、10、12 段）：PBO 0.39、0.32、0.55，結論相同。

**Reality check**（White 2000，studentized max-t，stationary bootstrap 平均區塊 10 天，1,000 次）：4,375 組裡有沒有任何一組真的比 v9 的係數好？

| 期間 | 最好的一組（t） | 純雜訊下 max t 的 95% 臨界值 | p |
|---|---|---|---|
| walk-forward 全期 | +0.27 bp/日（t 1.16） | 3.56 | 0.98 |
| val | +0.43（t 1.70） | 3.49 | 0.80 |
| rolling static + 10 月（99 天） | +7.38（t 3.61；只用 Transformer 的大盤觀點、bias −0.01 多猜 1） | 3.21 | 0.013 |

- 長期資料上沒有任何係數比 v9 的好。
- 6/1 以後這 99 天裡，確實有一組「真的」比較好（多猜 1），因為那段盤中平均轉正。但這是那一段的 regime（定理 5 的 Δ），不是之後會延續的證據：下一個表就是答案。

**用最近一段挑係數，用在接下來 19 天**（2022–2026 每 19 天一次，不重疊；4,375 組裡挑那一段最好的）：

| 用來挑的天數 | 次數 | 挑的那段比 v9 多 | 接下來 19 天比 v9 | t | 接下來 19 天贏 v9 的比例 |
|---|---|---|---|---|---|
| 15（像 10 月） | 60 | +14.14 | −2.51 | −2.06 | 38% |
| 60 | 58 | +6.58 | −1.99 | −2.29 | 31% |
| 84（像 static） | 56 | +5.21 | −1.46 | −1.84 | 39% |
| 99（像 static + 10 月） | 56 | +4.67 | −2.73 | −2.86 | 27% |
| 250 | 48 | +2.19 | −2.29 | −2.59 | 29% |

- 每一種長度都是負的：挑的那段看起來多 2–14 bp/日，接下來反而少 1.5–2.7。這和 v9 第十一節（每天依前 15 天調整：全部輸）、v11 第 7 節（w_T 0 連贏之後反轉）是同一件事，這次是用全部 4,375 組、各種長度驗證。
- W0 的係數（v9 格子裡的 w_T 0、λ 0.5）：前 99 天贏 v9 的 7 次，接下來 19 天平均 −5.58；前 99 天輸的 49 次，−1.47；全部 −1.99。

**Deflated Sharpe Ratio**（Bailey & López de Prado 2014；4,375 組的 Sharpe 變異數 0.00122）：v9、v11、W0、v5 的每日 Sharpe 0.27–0.32，把試過的設定數算成 100、4,375、100,000 組，DSR 都是 1.00。**核心的 edge 和挑了幾組無關**。但「增量」就不是：

| 增量 | 平均差 | t | 候選數 K | 純雜訊下 max t 的期望 | Bonferroni 5% 單尾門檻 |
|---|---|---|---|---|---|
| v11 − v9 | +0.71 | 1.19 | 7 | 1.35 | 2.45 |
| v9 − v5 | +0.93 | 1.68 | 26 | 1.98 | 2.89 |
| W0 − v11 | −2.80 | −2.52 | 240 | 2.81 | 3.53 |

**改法的 winner's curse**（`o3_shrinkage.py`；72 個有每日序列的改法，其中 65 個是單一改法：v10 的 48 個 Alpha158 群組、v11b 的 7 個、X5、v12 的 6 個、F1、F2、V10）：

- val 的差和 hold 的差，相關 +0.16；和 post 的差 −0.17。hold 對 val 的回歸斜率 0.29。
- 照 val > 0 入選的 32 個：val 平均 +0.256，hold −0.003，post +0.358；沒入選的 33 個：hold +0.019，post +0.921。**入選和沒入選在 hold、post 沒有差別**。
- 用 val 和 hold 的共變異估計「真正效果」的標準差：τ = 0.185 bp/日；val 差的雜訊標準誤 0.32。所以一個改法的 val 差，大約只有 τ²/(τ² + se²) ≈ 0.1–0.3 是真的（empirical Bayes 的收縮係數；標準誤越小越高）。
- 收縮後（只用 val）的估計：T2 +0.01、T3 +0.13、X1 +0.06（三個加起來 +0.20）、**v11 − v9 整體 +0.04**、v9 − v5 +0.06；就算把 hold、post 也算進去（會偏高），v11 − v9 也只有 +0.06、v9 − v5 +0.09 bp/日。
- 有趣的是 hold 和 post 的差彼此負相關（−0.36；非 Alpha158 的改法 −0.69）：2025–2026/05 有幫助的，2026-06 以後常常反過來，又是 regime。

## 4. 這對每天的上傳代表什麼

- **不需要因為 overfit 去改模型。** 成員模型會 overfit 訓練期，但 early stopping 已經停在對的地方，而所有決定都是看樣本外的數字。
- **不要再用「val > 0」或「hold、post 都 > 0」往上疊小改法。** 單一改法的真正效果大約只有 ±0.2 bp/日（τ = 0.185），而現有的資料（含重複使用過的 hold、post）分辨不了 2 bp/日以下的差。疊越多，只是把雜訊和新的 bug 風險疊進去。
- **不要用 static、10 月、live 的成績挑係數。** 理論上那幾十天分不出 30 bp/日以內的差（定理 3），歷史上這樣挑接下來 19 天平均少 1.5–2.7 bp/日（3.2 節）。
- **v9、v11、W0 怎麼選，是風險的選擇，不是誰比較不 overfit。** 長期期望 v11 ≈ v9（差 +0.04 到 +0.7，分不出來）> W0（約少 2–3）；W0 的波動小 20%，19 天 > 0 的機率差不多。和 v7 第三節、v11 第 6–7 節的建議相同：11/23 依 live 排行榜各隊的分數（領先要穩、落後要搏）決定 w_T、λ。
- 唯一真正的風險是漂移（尤其大盤觀點在 2026-06 以後翻負）。這不是 overfit，用更多歷史資料也證明不了；`v5\monitor_live.py`、`v6\phase2.bat` 的每天監控就是為了這個。
