## 1. 資料與時點

- `ext\cnyes\YYYY-MM.csv`（`fetch_news.py`）：newsId、publishAt（發布時間）、標題、摘要（前 300 字）、stock（台股代號標籤）。
- 第 t 天（預測日）、p = t 的前一個交易日（panel 的交易日曆）。視窗（台北時間）：
  - ON（隔夜）：(p 13:30, t 08:50]
  - PD（前一天盤中）：(p 08:30, p 13:30]
  - ATT（注意力）：(p 08:50, t 08:50]
- 只用 publishAt ≤ t 08:50 的文章；文章屬於標籤裡的每一支股票（一篇標多支就每支都算）。
- 檢查（在任何成績之前）：(a) 截斷測試：隨機 9 天，只留 publishAt ≤ t 08:50 的文章重算，第 t 天的 feature 必須相同；
  (b) 每個 feature 和當天 r 的 rank IC（只用 D）：|IC| > 0.30 表示可能偷看，停下來查；(c) 報告 08:50–09:00 發布的文章比例
  （發布時間是否可信）。

## 2. Feature（12 個；沒有文章時 count = 0、tone = 0、關鍵字 = 0）

| 名稱 | 定義 |
|---|---|
| nw_on | log(1 + ON 標到這支的篇數) |
| nw_on_solo | log(1 + ON 裡只標這一支台股的篇數)（公司自己的新聞，不含盤勢稿） |
| nw_pd | log(1 + PD 標到這支的篇數) |
| nw_abn | log(1 + ATT 篇數) − 前 20 個交易日同一數字的平均（至少 10 天） |
| tone_on | ON 標到這支的標題＋摘要：(正面詞次數 − 負面詞次數) / (正 + 負 + 1) |
| tone_pd | 同上，PD |
| kw_rev_on | ON 提到「營收」 |
| kw_earn_on | ON 提到 EPS、獲利、財報、季報、年報、每股純益、稅後 任一 |
| kw_rating_on | ON 提到 目標價、評等、調升、調降、喊進、喊出 任一 |
| kw_div_on | ON 提到 股利、配息、除息、配股 任一 |
| mkt_n_on | log(1 + ON 全部台股新聞篇數)（當天所有股票相同） |
| mkt_tone_on | ON 全部台股新聞的 tone（當天所有股票相同） |

正面詞：漲停、大漲、強漲、飆漲、創新高、新高、創高、利多、上修、調升、看好、優於預期、超乎預期、轉盈、獲利成長、營收成長、買超、
擴產、漲價、樂觀、強勁、回溫、亮眼。負面詞：跌停、大跌、重挫、崩跌、暴跌、新低、利空、下修、調降、看淡、低於預期、不如預期、
轉虧、虧損、衰退、賣超、減產、降價、保守、疲弱、下滑、砍單、示警。（子字串計次；「調升／調降」同時算在 tone 和評等關鍵字。）
