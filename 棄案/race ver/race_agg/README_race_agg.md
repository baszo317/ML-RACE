## 0. 結論

1. **16 個候選沒有一個過門檻（D 平均差 > 0、NW t ≥ 2、3 年至少 2 年 > 0），race 版不變。** 最接近的是 linear blending（A3）+0.77 bp/日
   （t 1.55，2023 −0.04）；Holm 校正後全部 p = 1。
2. **投影片的方法分成三群。**
   - **明顯比目前的 GBDT 差**（AR 較差，IC 的成對差 t −2.9 到 −6.1）：單一 C&RT −6.89、AdaBoost-DTree −5.09、AdaBoost-Stump −4.42、
     Random Forest −2.58（和 C.LU 平均也 −1.51）、squared-loss GBDT −0.97、exponential-loss GBDT −0.62。race 版用的
     **logistic loss 的 GBDT（LU）就是這張圖裡最適合這份資料的方法**；原因都在理論裡（命題 C、D、E、F）。
   - **IC 變好、AR 看不出來**：uniform blending（LU ＋ Baszo 的 MLP）每日 IC +0.0067（t 2.41），5 個 learner +0.0049（t 2.07），
     和命題 B 的預測幾乎一樣（預測 0.1282、實際 0.1274），但 AR −0.01、−0.16。Linear blending AR +0.77（t 1.55）、IC +0.0055（t 2.21）。
     AR 的成對差標準誤約 0.5 bp/日，IC 好 5% 只換算成約 +0.7–0.9 bp/日，D 的 727 天分不出來。
   - **其他**：10 個 seed −0.46、整天 bootstrap bagging −1.15、categorical 日曆 −0.75、permutation 選 feature −0.76、分數乘 absres_60 −0.55、
     stacking −0.90。
3. **事後發現（只報告）：race 版的 D 分數裡有約 +0.45 的 seed 運氣。** C.LU seed 1–3 在 D 是 15.10；seed 1–10 任取 3 個的 120 種組合平均
   只有 14.66（sd 0.31），seed 1–3 排第 9；10 個 seed 全部平均 14.64。B1（多加 seed）−0.46 就是這個運氣回到平均，IC 沒有變（−0.0007，
   t −1.02）。所以任何「重新長樹」的候選在 D 上先天吃虧約 0.4。扣掉這個，AdaBoost、CART、RF 仍然差 2–6.5 bp/日，換 loss 的 GBDT（C3、F1）
   的 IC 仍顯著較差（t −2.9、−3.0）；而 blending 改用 10 個 seed 的 LU 重做、和 10 個 seed 的 LU 比，LU ＋ MLP 各半是 +0.54（t 1.01）、
   IC +0.0073（t 2.66）——方向一致，但 AR 仍遠不到門檻。
4. **OOB（E3，只報告）在這份資料上不能直接用。** 一般 RF 的 row 層級 OOB 嚴重偏樂觀：葉子 50 時 OOB IC 0.227，真正的測試年只有
   0.11–0.14（三個 fold 都一樣，高估 1.7–2 倍，葉子越小越嚴重）；整天抽樣的 OOB 和往前驗證差不多。原因是同一天同產業的股票共享衝擊，row 層級 OOB 的樣本並不「沒看過」
   （命題 D）。
5. **對 11/23：race 版維持原樣**（C.LU、每天重訓、最近 3 天的模型平均、Top25 ＋除權息規則）。Blending 的 IC 證據是真的，但期望差只有
   約 0.5–1 bp/日，而 19 天的 private 期間兩版之差的標準誤約 3–4 bp/日；現在改 live 程式的風險大於期望收益。

  葉子越小，同一天同產業的 in-bag 夥伴在葉子裡的比重越高。葉子 50 時 row 層級 OOB 的 IC 是測試年的 1.7–2 倍，log-loss 0.648–0.651 對
  測試年 0.680–0.686。
- 選參數：三種方法（和事後的測試年）用 log-loss 在三個 fold 都選葉子 50，所以這裡 row 層級 OOB 沒有選錯——候選裡最小的剛好就是最好的；
  但它報出來的數字（IC 0.22）會讓人以為 RF 遠比 C.LU 好。
- 整天 OOB 和往前驗證在 2022、2023 都比測試年高，這是時間上的漂移（驗證的日子在訓練窗裡），不是 OOB 的問題。整天 OOB 可以代替往前驗證
  （不用切掉最後 120 天），但沒有比較準。
- 附帶：E1 依 v15 的設定只在 {250, 1000, 4000} 裡選，偏大；測試年最好的是 50，但葉子 50 的 RF 仍不如 C.LU（5.6 節）。

## 5. 理論（每個都有直觀和證明）

符號：e = 殘差報酬（盤中報酬 − 當天 100 支平均），y = 1{e > 0}，ỹ = 2y − 1 ∈ {±1}，w = min(|e|, c)、c = 5%。

### 5.1 命題 A：加權 logistic 的 GBDT 估計的是什麼

**敘述**：在 x 固定下最小化 R(p) = E[w·(−y ln p − (1 − y) ln(1 − p)) │ x]，唯一解是 p* = E[wy │ x] / E[w │ x]，而且
2p* − 1 = E[clip(e, ±c) │ x] / E[min(|e|, c) │ x]。

**直觀**：權重是 |e| 的時候，「猜漲」對的那一側收到的是正報酬的總量，「猜跌」對的那一側是負報酬的總量；最佳機率就是這兩堆的比例。
所以 LU 的機率排的是「期望報酬 ÷ 期望絕對報酬」，像一個 Sharpe ratio，不是期望報酬本身。

**證明**：令 A = E[wy │ x]、B = E[w(1 − y) │ x]，A, B ≥ 0，A + B = E[w │ x] > 0。R(p) = −A ln p − B ln(1 − p)，
R''(p) = A/p² + B/(1 − p)² > 0，嚴格凸；R'(p) = −A/p + B/(1 − p) = 0 ⇔ A(1 − p) = Bp ⇔ p* = A/(A + B)。
又 wy = min(|e|, c)·1{e > 0}、w(1 − y) = min(|e|, c)·1{e ≤ 0}，所以 A − B = E[min(|e|, c)·sign(e) │ x] = E[clip(e, ±c) │ x]
（e = 0 的機率為 0），2p* − 1 = (A − B)/(A + B)。∎

**推論（F2 的依據）**：Top50 剛好 25 支猜 1、沒有除權息時 Σs_i = 0，所以 AR = (1/50)Σ s_i r_i = (1/50)Σ s_i e_i（當天平均那一項抵消），
期望 AR 最大的決策是把 E[e_i │ x] 最大的 25 支猜 1。由命題 A，E[clip(e) │ x] = (2p* − 1)·E[min(|e|, c) │ x]，所以 (2p − 1) × 尺度
才是 AR 的排序。若估計誤差在 q = 2p − 1 的空間是同質的、先驗也相同，後驗平均 E[μ │ q̂, m] = m·g(q̂)（g 對每支股票相同且遞增），
乘上尺度 m 仍是 Bayes 最佳。實測 F2 −0.55（t −1.29）：模型的 p 離 p* 太遠（IC 只有 0.12），乘上 absres_60 放大的是高波動股的雜訊。

### 5.2 命題 B：uniform blending 與 linear blending

**(i) 投影片的分解**：G = (1/T)Σ g_t 時，(1/T)Σ_t E[(g_t − f)²] = E[(G − f)²] + (1/T)Σ_t E[(g_t − G)²]。

- 直觀：平均之後的誤差 = 成員的平均誤差 − 成員之間的分歧；成員越不一樣（又都差不多準），平均越有用。
- 證明：對每個 x，(1/T)Σ(g_t − f)² = (1/T)Σ[(g_t − G) + (G − f)]² = (1/T)Σ(g_t − G)² + (G − f)² + 2(G − f)·(1/T)Σ(g_t − G)；
  Σ(g_t − G) = TG − TG = 0，最後一項為 0。對 x 取期望即得。∎

**(ii) IC 的版本**：當天標準化的成員分數 s_k（平均 0、變異 1），標準化的目標 r，a_k = corr(s_k, r)，ρ_kl = corr(s_k, s_l)。則
corr(Σ_k s_k, r) = Σ_k a_k / √(Σ_k Σ_l ρ_kl)。兩個成員時 = (a₁ + a₂)/√(2 + 2ρ)。

- 直觀：分子是每個成員「對的部分」直接相加，分母是成員「一起動」的程度。ρ = 1 時分母 = K，什麼都沒得到。
- 證明：Cov(Σs_k, r) = Σ Cov(s_k, r) = Σ a_k；Var(Σs_k) = Σ_k Σ_l Cov(s_k, s_l) = Σ_kl ρ_kl；Var(r) = 1，代入相關係數的定義。∎
- 推論：兩個成員時（a₂ ≤ a₁），平均比單獨的 a₁ 好 ⇔ a₂/a₁ > √(2(1 + ρ)) − 1。C.LN 的 Top50 IC（0.1222）比 C.LU（0.1207）還高、
  兩者的日排序相關 0.795，所以 A1 的 IC 一定變高；C.LU 和 RF 的相關 0.868，門檻是 √3.736 − 1 = 0.93，RF 的 IC 只有 C.LU 的 0.88，
  所以 E2 的 IC 比 C.LU 低，和實測相同。

**(iii) 最佳線性權重**：max_w corr(Σ w_k s_k, r) 的解是 w* ∝ R⁻¹a（R = 成員的相關矩陣），最大值 √(a'R⁻¹a)。

- 證明：corr = w'a / √(w'Rw)。令 v = R^{1/2}w，corr = v'(R^{−1/2}a) / ‖v‖ ≤ ‖R^{−1/2}a‖（Cauchy–Schwarz），等號 ⇔ v ∝ R^{−1/2}a
  ⇔ w ∝ R⁻¹a。∎

**(iv) 估計權重的代價（為什麼等權常常贏）**：固定設計 Z（N × K、full rank）、y = Zβ + ε、ε 獨立、變異 σ²，least squares 的
E‖Zβ̂ − Zβ‖² / N = σ²K / N。

- 直觀：每多估一個權重，就多吸收約 σ²/N 的雜訊；等權不用估，沒有這個代價。只有「最佳權重比等權好的部分」大過 σ²K/N 時，
  linear blending 才划算。
- 證明：β̂ = (Z'Z)⁻¹Z'y，Zβ̂ − Zβ = Hε，H = Z(Z'Z)⁻¹Z' 對稱、冪等、trace(H) = trace((Z'Z)⁻¹Z'Z) = K。
  E‖Hε‖² = E[ε'H'Hε] = E[ε'Hε] = σ² trace(H) = σ²K。∎
- 代入：120 天、每天約 35 個等效獨立樣本（同產業相關，reg_svm 2.1）→ N ≈ 4,200，K = 6（5 個權重加截距），σ² ≈ Var(y)，代價約
  0.0014·Var(y)。D 上 5 個成員的 IC 0.106–0.122、相關 0.63–0.90；就算事後知道最佳權重（LN 0.50、LU 0.22、LC 0.19、LM 0.09、LP 0.01），
  IC 也只從等權的 0.1262 到 0.1295，多出的 R² = 0.1295² − 0.1262² ≈ 0.0008，比估計代價 0.0014 還小。所以預期 A3 的 IC 不會比 A2 好
  （實際 0.1262 對 0.1256，幾乎相同）；A3 在 AR 上多出的 +0.77 主要是雜訊，權重每個 fold 大幅跳動（4.1）也說明了這點。

### 5.3 命題 C：AdaBoost = 指數損失的逐步最小化

**(i) 投影片的演算法**：給定 G_{t−1}，令 u_n ∝ w_n exp(−ỹ_n G_{t−1}(x_n))。對任何 ±1 的 h 和 α > 0，
Σ_n w_n exp(−ỹ_n (G_{t−1} + αh)(x_n)) ∝ (1 − ε)e^{−α} + εe^{α}（ε = h 在 u 下的加權錯誤率）。所以最佳 h = 加權錯誤率最小的弱分類器，
最佳 α = ½ ln((1 − ε)/ε) = ln◆，更新後答錯的權重 × ◆、答對的 ÷ ◆。訓練的指數損失 = Π_t 2√(ε_t(1 − ε_t)) ≤ exp(−2Σ_t γ_t²)，γ_t = ½ − ε_t。

- 直觀：AdaBoost 每一步都在「目前的指數損失」下貪心地加一個弱分類器；答錯的點損失大，下一輪權重就大（diversity by re-weighting）。
- 證明：Σ u_n exp(−αỹ_n h(x_n)) = e^{−α}Σ_{ỹh = 1} u_n + e^{α}Σ_{ỹh = −1} u_n = (Σu)[(1 − ε)e^{−α} + εe^{α}]。固定 α > 0，這是 ε 的
  遞增函數（係數 e^{α} − e^{−α} > 0），所以 h 取 ε 最小。對 α 微分：−(1 − ε)e^{−α} + εe^{α} = 0 ⇒ e^{2α} = (1 − ε)/ε。新的
  u_n ∝ u_n e^{−αỹ_n h(x_n)}：答錯（ỹh = −1）乘 e^{α} = ◆，答對乘 e^{−α} = 1/◆。代回，最小值 = (Σu)·2√(ε(1 − ε))，連乘得訓練損失；
  2√(ε(1 − ε)) = √(1 − 4γ²) ≤ √(e^{−4γ²}) = e^{−2γ²}（用 1 − x ≤ e^{−x}）。∎
- 這份資料：ε_t 0.44–0.49，γ_t 只有 0.01–0.06；訓練損失下降很慢，驗證的指數損失在 2–47 輪就開始上升（4.2）。

**(ii) 母體最佳解**：min_F E[w e^{−ỹF} │ x] 的解 F* = ½ ln(A/B)（A、B 同命題 A）= ½ logit(p*)。和 logistic 的最佳解 logit(p*) 只差
一個遞增變換，排序完全相同。

- 證明：A e^{−F} + B e^{F} 對 F 嚴格凸，導數 −Ae^{−F} + Be^{F} = 0 ⇒ e^{2F} = A/B。∎

**(iii) 為什麼有限樣本下比較差**：單一點對梯度的貢獻，logistic |∂ℓ/∂F| = w·σ(−ỹF) ≤ w；指數 |∂ℓ/∂F| = w·e^{−ỹF}，margin 每差 1 就
乘 e。這裡 label 雜訊極大（SNR 約 0.01，大部分「答錯」其實是運氣），權重沒有上限的指數損失會把力氣集中在這些雜訊上（相關的理論：
Long & Servedio 2010 證明隨機 label 雜訊可以讓任何 convex potential booster 失敗）。實測：同樣的 GBDT 只換 loss（C3）IC −0.0037（t −2.88）；離散的
AdaBoost 還多了兩個問題——stump 只能做加法模型、±1 的輸出丟掉了信心大小——所以 −4.4、−5.1。

### 5.4 命題 D：相關資料下，row 層級 OOB 偏樂觀

**敘述**：設 e_it = μ(x_it) + δ_{g(i),t} + ε_it，δ_{g,t} 是第 t 天產業 g 的共同衝擊（變異 τ²，不同 (g, t) 互相獨立、和 μ 的估計獨立），
ε 獨立、變異 σ²。樹對某個 OOB row 的預測 = m̂ + λδ_{g,t} + ν，λ ∈ [0, 1] 是葉子裡同一天同產業 in-bag row 的權重，ν 是其他 row 的雜訊
平均。則「新的一天」的期望平方誤差比 OOB 的多 τ²λ(2 − λ) 到 2λτ²，都 ≥ 0。整天抽樣的 OOB 沒有同一天的 in-bag row（λ = 0），這一項消失。

- 直觀：葉子很小的樹可以用「當天的 macro feature ＋ 產業 feature」把某一天某個產業的股票圈在一起（C 組有 61 個 day-level feature，
  幾乎每一天都能被唯一辨識）。OOB 的那支股票，同一天同產業的夥伴多半在 in-bag 裡，葉子平均已經「看過」那天那個產業的衝擊；
  新的一天沒有這種夥伴。葉子越小，λ 越大，高估越多，所以用 row 層級 OOB 選參數會偏向小葉子。
- 證明：OOB row 的實際值是 μ + δ + ε，預測是 m̂ + λδ + ν，誤差 = E[(μ − m̂ − ν + (1 − λ)δ + ε)²] = E[(μ − m̂ − ν)²] + (1 − λ)²τ² + σ²
  （δ、ε 和其他項獨立、平均 0，交叉項期望為 0）。新的一天的衝擊 δ' 和訓練資料獨立，預測裡沒有 δ' 的成分；同樣大小的葉子裡若有某個
  訓練期 (g, t) 占權重 λ，預測多了 λδ̃（δ̃ 和 δ' 獨立、變異 τ²），誤差 = E[(μ − m̂ − ν)²] + λ²τ² + τ² + σ²。相減 = τ²[1 + λ² − (1 − λ)²]
  = 2λτ²；若新的一天落到的葉子沒有被單一 (g, t) 主導（λ²τ² 那一項不存在），差 = τ²[1 − (1 − λ)²] = τ²λ(2 − λ)。兩種情形都 ≥ 0，
  而且都隨 λ 遞增。∎
- 實測見 4.4：row 層級 OOB 減整天 OOB 的 IC，葉子 50 是 +0.08、250 是 +0.03、1000 以上約 0，三個 fold 都一樣；整天 OOB 和往前驗證接近。

### 5.5 命題 E：bagging 什麼時候有用

**(i) bootstrap 只用到約 63.2% 的資料**：從 n 天可重複抽 n 天，某一天沒被抽到的機率 (1 − 1/n)^n → e^{−1} ≈ 0.368。

- 證明：每次抽到某一天的機率 1/n，n 次都沒抽到是 (1 − 1/n)^n；n ln(1 − 1/n) = −1 − 1/(2n) − … → −1。∎ B2 實測 0.62–0.64。

**(ii) Breiman 的 aggregation 不等式**：squared error 下，E_D[(y − φ(x; D))²] ≥ (y − φ_A(x))²，φ_A(x) = E_D[φ(x; D)]。

- 直觀：把「換一份資料就會變」的部分平均掉只會讓誤差變小；但實際的 bagging 用的是 63% 的資料訓練出來的 φ，bias 變大，所以只有
  learner 不穩定（變異數大）時才划算。
- 證明：E_D[(y − φ)²] = y² − 2y·E_Dφ + E_Dφ² ≥ y² − 2yφ_A + φ_A² = (y − φ_A)²（Jensen：Eφ² ≥ (Eφ)²）。∎
- 實測：LU 的 seed 雜訊本來就小（10 個 seed 和 3 個 seed 的排序相關 0.994，Top25 每天只換 0.7 支），沒有變異數可降（B1 的 IC −0.0007）；
  B2 用 63% 的日子，bias 增加大於變異數下降（IC −0.003、AR −1.15）。

### 5.6 命題 F：單一棵樹、Random Forest 為什麼輸給 GBDT

**(i) 葉子要多大才分得出 edge**（v15 定理 6）：葉子裡 n 個樣本，加權勝率 ½ + τ 的估計標準誤約 1/(2√n)，要分辨 τ 需要 n ≳ 1/(2τ)²；
τ = 1–2% 時 n 約 600–2,500。單一棵樹只能用很少、很大的葉子 → D1 驗證選到 2–3 個葉子，同一天大部分股票同分，IC 0.072。

**(ii) Random Forest 只降變異數、不降 bias**：RF = 對很多棵 bias 相同的樹做平均，E[平均] = E[單棵]，所以 bias 不變（線性性），只有變異數
從 σ² 變成 ρ̄σ² + (1 − ρ̄)σ²/T。Breiman 的界 PE* ≤ ρ̄(1 − s²)/s² 在強度 s 很小（這裡每支股票的 margin 只有幾個百分點）時沒有意義。
GBDT 是加法模型，每一棵樹修正前面的殘差，能一點一點累積很多弱的效果（降 bias）；在 SNR 0.01 的資料上，需要的是累積微弱的 edge，
不是把很吵的深樹平均。E1 的葉子三個 fold 都選了候選裡最小的 250，E3 顯示 50 更好；但葉子 50 的 RF 測試年全市場 IC（0.114 / 0.113 /
0.135）每年都還是低於 C.LU（0.125 / 0.120 / 0.138）。

## 7. 這個結果不能說明的事

- **只用 D**：C.LU 本身是在 D 上挑出來的（4.3 量到 seed 運氣約 +0.45），所以在 D 上比「C.LU 加改法 − C.LU」偏向不利於會重新長樹的改法。
  A1–A3、F2 沿用 seed 1–3 的 C.LU，受影響較小。
- **年度重訓**：live 是每天重訓；這裡假設 aggregation 的效果和重訓頻率可以相加，沒有直接測。
- **檢定力**：成對差的 NW 標準誤 0.24–1.3 bp/日；小於約 1 bp/日的真實差異在 D 上分不出來。IC 精確得多，但比賽算的是 AR。
- **實作的近似**：C1 的 threshold 限在 255 個分位數 bin；C2 用權重代替「依 u 抽樣」（期望相同）；C&RT 的 surrogate branch 沒有實作
  （sklearn、LightGBM 都沒有）；RF 用 500 棵（v15 也是 500）。A3 / A4 的 LP 成員 g⁻ 用 sklearn 1.9.1 訓練，存好的 C.LP 是 1.7.2。
- **V 沒有打開**：規則寫明 D 沒有採用者就不打開，所以這裡沒有任何 2025 年以後的數字。
