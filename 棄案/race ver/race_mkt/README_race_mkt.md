## 0. 結論

1. **25/25 的上限並不低。** D（2022–2024）上，知道真實報酬時：Top25 = 108.65 bp/日，任何數量 = 118.61。限制成 25 支只少 8%
   （命題 3）。我們的 16.35 和 108.65 的差距是資訊不夠，不是 25/25 的規則。
2. **任何數量的方法做出來了**（DL1：s_i = sign(μ̂ + ĉ·q_i)，命題 1 證明這是最佳決策，μ̂ = 0 時就是 Top25），另外有 beta 版、
   直接學猜幾支、只在極端訊號下注、跳空反轉結構式、投票共 8 個版本。**D 上沒有一個過門檻**（差 −0.36 到 +0.32，t ≤ 0.35）；
   V（只算一次）−1.21 到 +1.47，t ≤ 0.76。
3. 原因：盤前資訊對 Top50 盤中報酬 m 的 OOS 相關只有約 0.12（每年都是正的，是真的，但很弱）。用它擇時，timing 多賺約 +3 到 +4.5，
   但偏離中位數讓選股少賺約 3 到 4，兩者抵銷。增益和相關的平方成正比（命題 2）：合成實驗顯示相關 0.2 才約 +1.8 bp/日、0.3 約 +4.6。
4. **期貨籌碼沒有帶來新資訊。** 37 個 feature（三大法人在 TX／MTX／TMF 的多空未平倉、散戶多空比、大額交易人、外資選擇權、P/C、
   基差、價差結構、OI×價格）：大盤預測的 OOS 相關只多 0.006（D 0.117 → 0.123、V 0.112 → 0.118），P2 − P1 +0.06（t 0.10）；

5. **race 版不變**（Top25 ＋除權息規則）。任何數量的版本是變異數的槓桿，不是 edge：V 每日 sd 42.7 → 52–63，19 天平均 > 30 bp 的比例

## 3. 命題與證明

記號：AR = (1/n)Σ s_i r_i，s_i ∈ {−1, +1}（猜 1 = +1），F = 09:00 前的資訊，m = (1/n)Σ r_i。

**命題 1（任何數量的最佳決策）。** E[AR | F] 的最大值由 s_i = sign(E[r_i | F]) 達成。寫 E[r_i | F] = μ + α_i（μ = E[m | F]，
α_i = E[r_i − m | F]），猜 1 的支數 = #{i : α_i > −μ}；μ = 0 且 α 的中位數為 0 時就是 Top25。

- 直觀：50 支是 50 個各自獨立的賭注，每一支只要押它的期望值的正負；Top25 等於假設「今天大盤期望是 0」。
- 證明：E[AR | F] = (1/n)Σ s_i E[r_i | F]，每一項只含自己的 s_i，所以可以逐項最大化；s_i E[r_i | F] ≤ |E[r_i | F]|，等號在
  s_i = sign(E[r_i | F]) 成立。代入 μ + α_i 即得支數的式子；μ = 0 時 s_i = sign(α_i)，α 中位數為 0 就是前 25 支。∎

**命題 2（大盤觀點的價值是平方級）。** 固定一天，最佳決策相對 Top25 的條件期望增益
g(μ) = (1/n)Σ [ |μ + α_i| − sign(α_i)(μ + α_i) ]。若 α 的橫斷面密度 f 在 0 附近連續，g(μ) = f(0)·μ² + o(μ²)；
α ~ N(0, σ_α²) 時 f(0) = 1/(σ_α√(2π))。大盤預測和 m 的相關為 ρ、聯合常態時 Var(μ) = ρ²σ_m²，所以 E[g] ≈ ρ²σ_m² / (σ_α√(2π))。

- 直觀：大盤觀點只會翻轉「選股觀點接近中間」的股票，大約 n·f(0)·|μ| 支；每支翻轉平均只賺 |μ|（翻之前它的期望值在 0 和 −μ 之間）。
  支數 × 每支的賺頭 = f(0)μ²，所以弱訊號的價值是平方級的小：相關從 0.1 到 0.2，價值變 4 倍；從 0.12 到 0.13（期貨籌碼的增量）幾乎是 0。
- 證明：只有 α_i 和 μ + α_i 異號的股票，最佳決策和 Top25 不同，每支的差是 |μ + α_i| − (−|μ + α_i|) = 2|μ + α_i|，其他股票的差為 0。
  以連續近似，μ > 0 時 g(μ) = 2∫_{−μ}^{0}(μ + a) f(a) da；令 x = μ + a，= 2∫_{0}^{μ} x f(x − μ) dx = 2 f(0)∫_{0}^{μ} x dx + o(μ²) = f(0)μ² + o(μ²)
  （f 在 0 連續，所以 f(x − μ) = f(0) + o(1)）。μ < 0 對稱。聯合常態時 μ = E[m | z] = E[m] + ρσ_m·z̃（z̃ 為標準化預測），
  中心化後 E[μ²] = ρ²σ_m²，代入即得。∎

**命題 3（25 支的完全資訊上限只比任意數量少一點）。** 知道真實 r 時，任意數量的最佳值是 (1/n)Σ|r_i|，限制 25 支的最佳值是
(1/n)(前 25 個 r 的和 − 後 25 個 r 的和)。兩者的差 = (2/n)Σ_{i∈W}|r_i|，W 是「落在錯的一半」的股票，|W| = |上漲家數 − 25|，
而且 W 正好是同號裡絕對值最小的那些。

- 直觀：只有上漲家數不是 25 的那幾支被迫押錯，而它們是當天漲跌最小的幾支，所以損失很小。
- 證明：設上漲家數 u ≥ 25（u < 25 對稱）。不限支數的最佳是 s_i = sign(r_i)。限 25 支時最佳是取 r 最大的 25 支，這 25 支都 > 0；
  剩下的 u − 25 支正報酬被放到後半（猜 0），而且它們是正報酬中最小的 u − 25 個。只有這些股票的符號和不限支數時不同，
  每支差 r_i − (−r_i) = 2r_i = 2|r_i|，其他股票相同。∎ D 上：118.61 − 108.65 = 9.96 bp/日（8.4%）。
