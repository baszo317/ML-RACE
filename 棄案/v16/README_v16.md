## 4. 理論（直觀＋證明）

### 4.1 Kalman filter 的一步就是常態的條件分佈（定理 1）

直觀：Kalman filter 每天做兩步。先用「狀態怎麼變」把昨天的估計往前推一天（預測），再用今天的觀察修正（更新）。
修正的幅度 K 由「預測有多不確定」和「觀察有多吵」的比例決定：預測越不確定、觀察越準，就越相信今天。
常態分佈下這兩步都是精確的條件分佈，所以得到的是條件期望，也就是平方誤差最小的估計。

**定理 1**：觀察 y_t = H_tθ_t + ε_t，ε_t ~ N(0, R_t)；狀態 θ_t = Φθ_{t−1} + c + η_t，η_t ~ N(0, Q_t)；所有雜訊互相獨立，也和起始狀態獨立。
若 θ_{t−1} | Y_{t−1} ~ N(θ̂_{t−1}, P_{t−1})（Y_{t−1} = 到 t−1 為止的觀察），則

1. θ_t | Y_{t−1} ~ N(θ̂_{t|t−1}, P_{t|t−1})，θ̂_{t|t−1} = Φθ̂_{t−1} + c，P_{t|t−1} = ΦP_{t−1}Φ' + Q_t；
2. y_t | Y_{t−1} ~ N(H_tθ̂_{t|t−1}, F_t)，F_t = H_tP_{t|t−1}H_t' + R_t；
3. θ_t | Y_t ~ N(θ̂_{t|t−1} + K_tv_t, P_{t|t−1} − K_tF_tK_t')，v_t = y_t − H_tθ̂_{t|t−1}，K_t = P_{t|t−1}H_t'F_t^{−1}；
4. log p(y_1, …, y_T) = −½ Σ_t (log 2πF_t + v_t'F_t^{−1}v_t)。這就是三個候選用來選 q 的 likelihood。

證明：
1. 給定 Y_{t−1}，θ_{t−1} 是常態，η_t 和它獨立也是常態；常態的線性組合是常態，平均 Φθ̂_{t−1} + c，變異 ΦP_{t−1}Φ' + Q_t。
2. y_t = H_tθ_t + ε_t，ε_t 和 (θ_t, Y_{t−1}) 獨立，同理。
3. 給定 Y_{t−1}，(θ_t, y_t) 是聯合常態，Cov(θ_t, y_t) = P_{t|t−1}H_t'。常態的條件分佈：
   E[θ | y] = E[θ] + Cov(θ, y)Var(y)^{−1}(y − E[y])，Var(θ | y) = Var(θ) − Cov(θ, y)Var(y)^{−1}Cov(y, θ)。代入就是 3。
4. 連鎖律 p(y_1, …, y_T) = Π_t p(y_t | Y_{t−1})，每一項是 2 的常態密度。∎

三個候選的對應：K1 θ = (α, β)、H_t = (1, m_t)、Φ = diag(1, φ)、c = (0, 1 − φ)、Q = diag(0, q)；
K2 θ = (a, b)、H_t = (1, x_t)、Φ = I、Q_t = diag(q_aR_t, q_bR_t/0.03²)；K3 是一維的 local level（v15 定理 7）。
雜訊不是常態時，同一組式子仍是「線性估計裡平方誤差最小」的（推導只用到平均和共變異），但 4 只是近似的 likelihood。

### 4.2 q = 0 就是用全部過去資料的固定參數（定理 2）

直觀：如果參數不會變（q = 0），Kalman filter 每天只是在累積資訊：今天的估計 = 起始的猜測和到昨天為止所有資料的加權平均，權重是各自的精確度。
這就是 ridge 形式的 Bayesian 回歸；資料夠多時就是用全部過去資料的 OLS（觀察的權重 1/R_t）。
所以三個候選在 q = 0 時都等於「固定參數」：K1 是 2020 年起全部資料的 beta，K2 是 2022 年起係數固定的回歸（大盤項等於 v11），K3 是 2022 年起 v11 − W0 的累積平均。
候選和固定參數的差，只來自 q > 0。

**定理 2**：Φ = I、c = 0、Q = 0，起始 θ ~ N(θ_0, P_0)。則
P_{t|t−1}^{−1} = P_0^{−1} + Σ_{s<t} H_s'R_s^{−1}H_s，θ̂_{t|t−1} = P_{t|t−1}(P_0^{−1}θ_0 + Σ_{s<t} H_s'R_s^{−1}y_s)。

證明：先證更新的 information form（省略下標，P = P_{t|t−1}，A = P^{−1} + H'R^{−1}H）：(a) P_{t|t} = A^{−1}；(b) P_{t|t}^{−1}θ̂_{t|t} = P^{−1}θ̂_{t|t−1} + H'R^{−1}y_t。

- 引理：PH'(HPH' + R)^{−1} = A^{−1}H'R^{−1}。兩邊左乘 A、右乘 (HPH' + R)：左邊 = (P^{−1} + H'R^{−1}H)PH' = H' + H'R^{−1}HPH' = H'R^{−1}(R + HPH')，
  右邊 = H'R^{−1}(HPH' + R)，兩者相同；A 和 HPH' + R 都可逆，所以原式成立。所以 K = A^{−1}H'R^{−1}。
- (a)：P_{t|t} = P − KHP = P − A^{−1}H'R^{−1}HP = A^{−1}(A − H'R^{−1}H)P = A^{−1}P^{−1}P = A^{−1}。
- (b)：θ̂_{t|t} = θ̂ + A^{−1}H'R^{−1}(y − Hθ̂)。左乘 A：Aθ̂_{t|t} = Aθ̂ − H'R^{−1}Hθ̂ + H'R^{−1}y = P^{−1}θ̂ + H'R^{−1}y。

Q = 0、Φ = I 時預測步不改變 θ̂ 和 P，所以 P_{t+1|t} = P_{t|t}、θ̂_{t+1|t} = θ̂_{t|t}。從 P_{1|0} = P_0、θ̂_{1|0} = θ_0 開始對 t 歸納，把每天的 (a)、(b) 加起來就得到定理。∎

### 4.3 120 天 OLS 等於記憶 60 天的 Kalman（定理 3）

直觀：如果 beta 每天隨機漫步一點點，Kalman 的 beta 就是過去每天「r_t / m_t」的指數加權平均（大盤動得小的日子權重小），
記憶長度由「beta 每天變多少」對「一天的資料能說多少 beta」的比例決定。固定窗的 OLS 也是一種平均：
120 天等權重，和「記憶 60 天的指數加權」有一樣的變異、一樣的平均落後天數。

**定理 3**：
(a) 觀察 y_t = β_tx_t + ε_t、Var(ε_t) = R，β_t = β_{t−1} + η_t、Var(η) = q。若 x_t² ≈ s²（固定），則 z_t = y_t/x_t = β_t + ε_t/x_t 是 local level，雜訊變異 R/s²，
訊雜比 r = qs²/R；穩態增益 K = (−r + √(r² + 4r))/2，β̂ 是 z 的 EWMA（權重 K），記憶 1/K 天。
(b) 雜訊互相獨立、變異 σ² 時，最近 n 天的等權平均和增益 K 的 EWMA 變異相同，若且唯若 K = 2/(n + 1)；這時兩者的平均落後天數也相同（(n − 1)/2）。所以 120 天 OLS ≈ 記憶 60.5 天。

證明：
(a) 兩邊除以 x_t 得到 local level，代入 v15 定理 7（穩態增益 K* = (−q + √(q² + 4q))/2，q 換成 r）。
(b) 等權平均的變異 σ²/n。EWMA 的權重 K(1 − K)^j，變異 Σ_j K²(1 − K)^{2j}σ² = K²σ²/(1 − (1 − K)²) = Kσ²/(2 − K)。
相等 ⟺ K/(2 − K) = 1/n ⟺ K = 2/(n + 1)。平均落後：等權 Σ_{j=0}^{n−1} j/n = (n − 1)/2；EWMA Σ_j jK(1 − K)^j = (1 − K)/K，代入 K = 2/(n + 1) 得 (n − 1)/2。∎

資料：K1 選到 φ 0.999、q 1e−3（2023 是 φ 1、q 3e−4），用 fold 之前的 E[m²] 和 R 的中位數換算，記憶 52–58 天（2023 是 95 天）；120 天 OLS 是 60.5 天。
MLE 自己找到的就是現在的窗。φ 0.999 的均值回歸半衰期 693 天，在 60 天的尺度上幾乎沒有作用。

### 4.4 任何濾波器偵測一個變化至少要多少天（定理 4）

直觀：要知道「係數變了」，得先累積夠多變了之後的資料，讓變化大過雜訊。就算知道變化從哪天開始、變之前和變之後各是多少（比任何濾波器知道的都多），
能分辨的程度也只取決於「變化 × √天數 ÷ 雜訊」。這是所有方法的上限。濾波器調得越快，越早看到真的變化，但也越常被雜訊騙。

**定理 4**：變化之後的 L 天，y_t = θx_t + ε_t，ε_t 獨立 N(0, σ²)，x_t 已知。檢定 H₁：θ = θ₁（沒變）對 H₂：θ = θ₂（變了），兩個值和變化的日期都已知。
在「沒變時說變了」的機率為 α 的所有方法裡，抓到變化的機率最高是 Φ(d − z_{1−α})，d = |θ₂ − θ₁|·√(Σx_t²)/σ。
任何濾波器「這 L 天之後切換」的決定都是這樣一個檢定，所以不會更好。

證明（Neyman–Pearson）：設 θ₂ > θ₁（反過來時對稱）。log-likelihood ratio = [(θ₂ − θ₁)/σ²]·Σx_ty_t − [(θ₂² − θ₁²)/(2σ²)]·Σx_t²，是 T = Σx_ty_t 的遞增函數。
Neyman–Pearson 引理：在誤判率 α 下檢定力最高的檢定是「likelihood ratio 大就判定變了」，也就是 T 大就判定變了。θ = θ_k 時 T ~ N(θ_kS, σ²S)，S = Σx_t²。
誤判率 α 的門檻是 θ₁S + z_{1−α}σ√S，檢定力 P(N(θ₂S, σ²S) > θ₁S + z_{1−α}σ√S) = Φ((θ₂ − θ₁)√S/σ − z_{1−α})。∎

推論：要 d = 2（α 5% 單邊時抓到的機率 Φ(0.355) = 0.64），大約要 L = 4σ²/(Δ²s²) 天（s² = x² 的平均）。
相關係數小時，斜率的變化換成相關係數的變化 Δρ，每天的分辨力就是 Δρ。代入這份資料（`results\v16_posthoc.txt` 第 3 部分、`v16_eval.txt`）：

| 要追的變化 | 每天的雜訊 σ | 每天的分辨力 Δ·s/σ | d = 2 要幾天 |
|---|---|---|---|
| 一支股票的 beta 變 0.2（K1） | 個股殘差 132 bp；s = m 的 sd 82 bp | 0.124 | 260 |
| 大盤觀點和大盤的相關從 +0.20 掉到 0（K2，hold → post） | — | 0.19 | 111 |
| 大盤盤中的漂移變 10 bp/日（K2 的截距） | m50 的 sd 76 bp | 0.13 | 231 |
| v11 − W0 從 hold 的 +3.99 變成 post 的 −1.36（K3） | 每天差的 sd 36 bp | 0.148 | 183 |
| v11 − W0 變成 10 月那樣（相對長期約差 17 bp/日） | 36 bp | 0.47 | 18 |
| 一支股票的盤中偏向變 10 bp/日（v15 D1） | 個股殘差 132 bp | 0.076 | 697 |

讀法：

- beta 變 0.2 要約 260 天的資料才分得出來，所以估 beta 時「跟得快」和「估得準」互相衝突；MLE 選的 55 天左右是兩者的平衡點，120 天 OLS 剛好在同一點（定理 3），Kalman 沒有額外的空間。
- 大盤觀點的相關從 +0.20 掉到 0 要約 111 天，post 到 10/22 才 99 天；v11 − W0 從 hold 到 post 的變化要約 183 天。
- 倒數第二列只要 18 天，但前提是這種差距會持續一個月以上；v11 − W0 月平均的自我相關是 −0.14（overfit 研究 −0.21），也就是不會持續，K3 的 MLE 看了 2022 起的歷史也選了 q = 0。
- 調得快的代價可以直接看強迫調整的結果（第 5.2、5.3 節）：K2 固定 q_b 的三種在 val、post 都輸（只有 hold 有兩種是正的），K3 半衰期 20 天三段都輸。

### 4.5 beta 的預測誤差怎麼量

直觀：好的 beta 應該讓「今天的個股報酬 − beta × 今天的大盤」的誤差變小。這個誤差可以直接算，雜訊比 AR 小很多。

**命題**：r_t = α + β_tm_t + ε_t，β̂_t 只用到 t−1 的資料，ε_t 和 (β_t − β̂_t, m_t) 獨立、平均 0，m_t 和 β_t − β̂_t 獨立。則
E[(r_t − β̂_tm_t)²] = E[m_t²]·E[(β_t − β̂_t)²] + σ² + α² + 2αE[m_t]E[β_t − β̂_t]。

證明：r_t − β̂_tm_t = α + (β_t − β̂_t)m_t + ε_t，展開平方；含 ε_t 的交叉項期望為 0（獨立、平均 0）；
(β_t − β̂_t)²m_t² 的期望由獨立性分開成 E[m_t²]E[(β_t − β̂_t)²]；剩下 α² 和 2αE[m_t]E[β_t − β̂_t]。∎

兩種 beta 的誤差相減時 σ²、α² 消掉；盤中的 E[m_t] 約 −8 bp（sd 82 bp），α 只有幾 bp，最後一項比要比的差小好幾個數量級，可以忽略。所以「每天平均誤差的差 ÷ m² 的平均」估的就是 beta 的 MSE 差。
程式算 Top50、走 walk-forward 的每一天，beta 都照對沖的方式截斷到 [0.2, 2.5]。

### 9.0 結論

- **smoother 不能拿來預測。** 只用 D−1 以前的資料時，smoother 對 D 的預測和 filter 逐位相同（定理 5；S1 實測 K1、K2、K3 的差都是 0）。
  smoother 和 filter 會不一樣只有兩種情形：偷看未來，或只在訓練窗裡做 label。
- **偷看版（S2）的「好成績」全部來自未來。** 用第一部分選到的參數（大多 q = 0）時，偷看版也和 v11 幾乎一樣（K1 −0.08、K2 −0.07、K3 0）；
  把平滑調快才出現漂亮的數字：K2 固定 (q_a, q_b) = (1e−3, 1e−2) 全期 +8.59（t 7.60）、K3 半衰期 5 天 +3.46（t 6.34）；連「用前一天的平滑值」也有 +6.99、+2.81。
  同一個設定用合法的 filter 是負的（K2 q_b 1e−2：−1.85），差的 8 bp/日全部是未來的資訊。這就是論文裡 smoother 看起來很有效的原因，09:00 拿不到這些數字。
- **合法的用法（S3：只在訓練窗把 label 平滑）照事先的規則「通過」，但我不建議用。**
  - 規則：(v11 + S3a、S3b) − (v11 + 對照) val +0.23、hold +0.83、post +0.82，兩段都 > 0 → 通過；和 v11 本身比 +0.06 / +0.65 / +1.85 / 全期 +0.38（t 1.00）。

  - 分數變好來自「和現有選股觀點不像」（相關 0.35–0.56）：加一點點進去，選股觀點的 IC 只多 0.0013（t 1.34），換算約 0.04–0.08 bp/日；收縮後的期望 +0.07 bp/日。

### 9.1 smoother 只在最後一點等於 filter，其他點用到未來（定理 5）

直觀：filter 在 t 只看到 t 以前。smoother 在 t 先把整段資料看完再回頭修正：t 之後的資料顯示狀態往上走，就把 t 的估計也往上拉。
所以在最後一天，smoother 沒有「之後的資料」可用，就是 filter；在其他天，修正的量是之後每一天預測誤差的線性組合。

**定理 5**：定理 1 的 state space model，T 天的資料 Y_T。RTS smoother θ_{t|T} = E[θ_t | Y_T] 滿足
θ_{t|T} = θ_{t|t} + J_t(θ_{t+1|T} − θ_{t+1|t})，J_t = P_{t|t}Φ'P_{t+1|t}^{−1}，從 θ_{T|T} 往回算（變異 P_{t|T} = P_{t|t} + J_t(P_{t+1|T} − P_{t+1|t})J_t'）。因此

1. θ_{T|T} 就是 filter 的值；
2. 只用 Y_{D−1} 時，不管先跑 smoother 還是只跑 filter，對 D 的預測都是 E[θ_D | Y_{D−1}] = Φθ_{D−1|D−1} + c，兩者逐位相同；
3. t < T 時，θ_{t|T} − θ_{t|t} 是之後的預測誤差 v_{t+1}, …, v_T 的線性組合，一般不是 0。

證明：

1. Markov 性質：給定 θ_{t+1}，θ_t 和 y_{t+1}, …, y_T 條件獨立（之後的觀察只透過 θ_{t+1}, θ_{t+2}, … 和它們自己的雜訊產生，和 θ_t 的關係都經過 θ_{t+1}）。
   所以 E[θ_t | θ_{t+1}, Y_T] = E[θ_t | θ_{t+1}, Y_t]。
2. 給定 Y_t，(θ_t, θ_{t+1}) 是聯合常態：Cov(θ_t, θ_{t+1} | Y_t) = P_{t|t}Φ'，Var(θ_{t+1} | Y_t) = P_{t+1|t}。
   常態的條件期望：E[θ_t | θ_{t+1}, Y_t] = θ_{t|t} + J_t(θ_{t+1} − θ_{t+1|t})。
3. 對 θ_{t+1} | Y_T 取期望（塔性質）：θ_{t|T} = θ_{t|t} + J_t(θ_{t+1|T} − θ_{t+1|t})。變異用總變異公式同理。
4. 第 1 點是遞迴的起點。第 2 點：E[θ_D | Y_{D−1}] 只有一個；smoother 在 Y_{D−1} 上的最後一點是 θ_{D−1|D−1}（第 1 點），往前一步是 Φθ_{D−1|D−1} + c，就是 filter 的預測步。
5. 第 3 點對 t 往回歸納：θ_{T|T} − θ_{T|T−1} = K_Tv_T。若 θ_{t+1|T} − θ_{t+1|t+1} 是 v_{t+2}, …, v_T 的線性組合，則
   θ_{t+1|T} − θ_{t+1|t} = (θ_{t+1|T} − θ_{t+1|t+1}) + K_{t+1}v_{t+1} 是 v_{t+1}, …, v_T 的線性組合，乘上 J_t 就是 θ_{t|T} − θ_{t|t}。∎

所以只要是在 D−1 以前的資料上算的 smoother，就沒有任何新東西。「先把整段平滑，再用 D−1 的平滑值預測 D」也一樣偷看：θ_{D−1|T} 含有 v_D 以後的預測誤差（第 3 點）。

### 9.2 兩邊平滑的 label 會讓模型學到假的過去報酬係數（定理 6）

直觀：把每天的超額報酬平滑後當 label，第 t 天的 label 裡有一部分就是第 t−1、t−2 天的報酬，而這些報酬本來就在 feature 裡（rel_intra_prev 就是前一天的 e）。
模型很容易「預測」到 label 裡屬於過去的那一塊，所以會給過去的報酬一個正的係數（動能）。但測試時要預測的是第 t 天本身的 e，它和昨天的 e 其實是輕微反轉。

**定理 6**：e_t 平穩，自我共變異 γ(k)、自我相關 ρ(k)，label ỹ_t = Σ_k w_k e_{t+k}。

1. 用 e_{t−1} 預測 ỹ_t 的母體回歸係數是 Σ_k w_k ρ(k + 1)；e 是白雜訊時就是 w_{−1}，R² = w_{−1}²/Σ_k w_k²。用 e_{t−1} 預測真正的 e_t，係數是 ρ(1)。
2. local level 的 RTS smoother 在穩態、資料很長時，中間的點 s_t = Σ_k w_k e_{t+k}，w_k = ((1 − λ)/(1 + λ))·λ^{|k|}，λ = 1 − K（K 是 filter 的穩態增益）。
   所以白雜訊時 R² = λ²(1 − λ²)/(1 + λ²)：半衰期 5 天（K 0.129）是 0.104，20 天（K 0.034）是 0.032。
3. 只往後看的 label f_t = KΣ_{j≥0}(1 − K)^j e_{t+j}，係數是 KΣ_{j≥0}(1 − K)^j ρ(j + 1)：沒有 w_{−1} 那一項，正負號跟著 ρ(1) 走。

證明：

1. Cov(ỹ_t, e_{t−1}) = Σ_k w_k Cov(e_{t+k}, e_{t−1}) = Σ_k w_k γ(k + 1)，除以 Var(e_{t−1}) = γ(0)。白雜訊時只剩 k = −1。
   單一變數回歸的 R² = Cov(ỹ_t, e_{t−1})²/(Var(ỹ_t)Var(e_{t−1})) = w_{−1}²γ(0)²/(Σ_k w_k²γ(0)·γ(0)) = w_{−1}²/Σ_k w_k²。
2. 穩態時（以 Var(ε) 為單位）預測變異 P、增益 K = P/(P + 1)、filter 之後的變異 P_f = P/(P + 1) = K，而 q = K²/(1 − K)（v15 定理 7）。
   所以 RTS 的 J = P_f/(P_f + q) = K/(K + K²/(1 − K)) = 1 − K = λ。
   filter 是 a_t = (1 − λ)Σ_{i≥0}λ^i e_{t−i}；smoother 是 s_t = a_t + λ(s_{t+1} − a_t) = (1 − λ)a_t + λs_{t+1} = (1 − λ)Σ_{j≥0}λ^j a_{t+j}。
   合起來 s_t = (1 − λ)²Σ_{i,j≥0}λ^{i+j}e_{t+j−i}；e_{t+k} 的權重 = (1 − λ)²Σ_{j−i=k}λ^{i+j} = (1 − λ)²λ^{|k|}/(1 − λ²) = ((1 − λ)/(1 + λ))λ^{|k|}。
   Σ_k w_k² = ((1 − λ)/(1 + λ))²(1 + λ²)/(1 − λ²)，代入第 1 點得 R² = λ²(1 − λ²)/(1 + λ²)。
3. Cov(f_t, e_{t−1}) = KΣ_{j≥0}(1 − K)^j γ(j + 1)，除以 γ(0)。∎

資料（S3 的訓練窗）：label 對前一天 e 單獨回歸的 R²，S3a 0.092、S3b 0.030（理論 0.104、0.032），對照 0.001、只往後看的 S3f 0.000；
前一天超額報酬（rel_intra_prev）的係數：對照 −16.5（反轉）、S3a +6.3、S3b +1.1（變成動能）、S3f −3.8（還是反轉）。

### 9.5 事後分析（`results\v16_smoother_posthoc.txt`，看到判定之後才寫，只報告）

問題：S3 自己的 IC 掉很多，分數為什麼還變好？

- 選股觀點的 IC（v11 的 p_e 加上 S3 之後）：v11 0.1105 → + S3a 0.1114（+0.0009，t 0.82）、+ S3b 0.1119（+0.0014，t 1.40）、+ 兩個 0.1118（+0.0013，t 1.34）；+ 對照 0.1096（−0.0009）。
- 原因是「不像」：和 v11 選股觀點的每天排序相關，對照 0.80、S3f 0.74、S3b 0.56、S3a 0.35。README_v14 定理 2 的條件 IC_z − ρIC_x：對照 +0.003、S3a +0.020、S3b +0.021。
  兩邊平滑的 label 讓模型學到的東西（假的動能）和現有成員很不一樣，加一點點就能讓整體 IC 稍微變高，但它本身不是更好的預測。
- 分數的拆解（S3a + S3b − v11，全期）：timing +0.21、xsec +0.17，猜 1 的比例 0.592 對 0.588；有一半來自 timing，不是選股。
- 換算：選股觀點的 IC 多 10⁻³，Top50 AR 約多 0.03–0.06 bp/日（v11 第一部分），所以 +0.0013 只值約 0.04–0.08；觀察到的 +0.38–0.45 大約是它的 5–10 倍，多出來的是雜訊。
  用 overfit 研究的先驗（真實效果的 sd τ = 0.185 bp/日）收縮：對對照 +0.45 → +0.09，對 v11 +0.38 → +0.07 bp/日。

### 9.6 我的判斷

照規則 S3 通過，要不要寫成每天的程式由你決定（11/23 前）。我的建議是不要：

1. 它不是「去噪」。S3a 自己的 IC 低很多（t −5.39），學到的是定理 6 說的假動能；S3b 也低（t −1.55）。
2. 分數的來源是「和現有模型不像」，選股觀點的 IC 只多 0.0013（t 1.34），值 0.04–0.08 bp/日；收縮後的期望 +0.07 bp/日。
3. W0 版本是負的（S3a −0.38、S3b −0.43；post −3.49、−4.44）。
4. 全期 t 只有 1.0–1.2；沒有效果時這個規則通過的機率 ≤ 1/4，而 v11、v12、v13、v15 也有很多「三段都正」最後沒用的例子。

只往後看的平滑（S3f）是唯一讓模型自己的 IC 變高的（+0.0080，t 1.90），和 v15 B3、B4 的多天 target 同一件事；但放進 v11 只多 +0.17（t 0.55），不夠。
