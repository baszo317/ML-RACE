## 1. 設計：把「label 帶多少資訊」和「損失函數」分開

| label 的資訊 \ 損失 | pointwise | pairwise（沒有位置折扣） | lambdarank（NDCG） |
|---|---|---|---|
| 正負：1{resid_r > 0} | Y1 lgb_sign（binary，沒有權重） | | |
| 正負 + 大小權重 | lgb_res（v9 現有：binary，權重 min(\|resid_r\|, 5%)） | | |
| 十分位：同一天內 resid_r 的十分位 0–9 | Y2 lgb_dec_l2（L2 regression） | Y4 lgb_dec_pw | X5 lgb_rank（v11 第 9 節） |
| 報酬大小：clip(resid_r, −5%, 5%) | Y3 lgb_size_l2（L2 regression） | Y5 lgb_size_pw | Y6 lgb_size_rank |

- **pairwise**：同一天的每一對 (i, j)，label 較高的是 i，損失 w_ij · log(1 + exp(−(s_i − s_j)))，w_ij = |label_i − label_j|，
  每天把 w 乘上同一個常數，讓每支股票的 w 總和平均 = 1。這等於把 lambdarank 每一對的權重 |ΔNDCG| 換成 |Δlabel|，
  所以 **Y4 和 X5、Y5 和 Y6 都只差在有沒有位置折扣**。用 LightGBM 的自訂損失，梯度和 hessian 用 numba 算
  （先用合成資料和直接計算、數值微分核對過，誤差 < 10⁻¹⁵）。
- **Y6**：label 用 0.25% 一格的等級 0–40，label_gain 線性（gain 和報酬成正比），其他和 X5 相同。
- **共同**：B 的 67 個 feature，lgb_res 的參數（learning rate 0.02、num_leaves 15、min_data_in_leaf 500、feature_fraction 0.8、
  bagging 0.8、lambda_l2 1）；pointwise 以列 bagging（同 lgb_res），pairwise、lambdarank 以天 bagging（同 X5）；
  最多 1000 輪，用訓練期最後 120 天、各自的損失 early stopping（patience 100），再用全部訓練資料重訓；
  seed 1–5 × 6 個年度 fold，每個 30 個模型（共 180 個，雲端 2 核 33 分鐘，0 個失敗）。
- 指標：每個模型（5 個 seed 平均）每天的 rank IC（當天約 100 支），兩兩比較用每天 IC 的差（平均、NW t）。
  判定（事先定好）：全期差 > 0、t ≥ 2 而且 val、hold 都 > 0 →「好」；反過來 →「差」；全期 |差| < 0.002 且 |t| < 2 →
  「差不多」；其他「不確定」。

## 3. 數學：為什麼 L2 的 pointwise 本來就是同一天的兩兩比較

**命題**：同一天 n 支股票，分數 s_1, …, s_n，label y_1, …, y_n，s̄、ȳ 是當天的平均。則

(1) Σ_{i<j} [(s_i − s_j) − (y_i − y_j)]² = n · Σ_i [(s_i − s̄) − (y_i − ȳ)]²

(2) Σ_i (s_i − y_i)² = (1/n) · Σ_{i<j} [(s_i − s_j) − (y_i − y_j)]² + n · (s̄ − ȳ)²

**直觀**：
- 兩兩比較只看「誰比誰高多少」，整天的分數一起加一個常數，兩兩的差都不變；所以它只看得到每支股票的誤差
  e_i = s_i − y_i 離「當天平均誤差」有多遠。
- 一群點「兩兩距離的平方和」等於「n 倍的、每個點離平均的距離平方和」（就像兩兩距離平方的平均是變異數的 2 倍）。這就是 (1)。
- 所以 pointwise 的 L2 = 同一天兩兩比較的 L2 除以 n，再加上「當天平均分數和平均 label 差多少」。後一項只管整天的高低，
  和同一天內誰排前面無關。這就是 (2)。

**詳細證明**：令 e_i = s_i − y_i，ē = (1/n) Σ_i e_i = s̄ − ȳ。

1. (s_i − s_j) − (y_i − y_j) = (s_i − y_i) − (s_j − y_j) = e_i − e_j。
2. i = j 的項是 0，(i, j) 和 (j, i) 的項相同，所以 Σ_{i<j} (e_i − e_j)² = ½ Σ_{i=1}^{n} Σ_{j=1}^{n} (e_i − e_j)²。
3. 展開 (e_i − e_j)² = e_i² − 2 e_i e_j + e_j²，對 i、j 各加 n 項：
   ½ Σ_i Σ_j (e_i − e_j)² = ½ [n Σ_i e_i² − 2 (Σ_i e_i)(Σ_j e_j) + n Σ_j e_j²] = n Σ_i e_i² − (Σ_i e_i)² = n Σ_i e_i² − n² ē²。
4. Σ_i (e_i − ē)² = Σ_i e_i² − 2 ē Σ_i e_i + n ē² = Σ_i e_i² − 2n ē² + n ē² = Σ_i e_i² − n ē²。
5. 由 3、4：Σ_{i<j} (e_i − e_j)² = n (Σ_i e_i² − n ē²) = n Σ_i (e_i − ē)²；又 e_i − ē = (s_i − s̄) − (y_i − ȳ)，得到 (1)。
6. 由 4：Σ_i e_i² = Σ_i (e_i − ē)² + n ē²；把 5 代進第一項、ē = s̄ − ȳ 代進第二項，得到 (2)。∎

**意義**：
- Y2（label = 十分位）和 Y3（label = 報酬大小）的 L2 本來就是「同一天兩兩比較」的平方損失，只多一項管當天平均。
  所以在 L2 底下 pointwise 和 pairwise 不是兩回事；實驗裡 Y3 和 Y5（同樣資訊、pairwise logistic）也確實差不多
  （−0.0002，t −0.11）。
- Y2 的損失是讓同一天兩支股票的分數差去逼近十分位差（名次差的粗略版），和我們量的 rank IC 最接近；
  這可能是 Y2 的 IC 最高的原因（推論，沒有另外做實驗）。
- lgb_res 的 binary logloss 沒有這麼乾淨的等式，但 label 是「贏過當天平均」，每天大約一半是 1，模型學的也是同一天內的
  相對高低；C1 的實驗結果（Y5 沒有比 lgb_res 好）和這一致。

## 6. 事後分析（不在事先寫好的規則裡，`research\v12_posthoc.py` → `results\v12_posthoc.txt`）

為什麼 Y2 的 IC 比較高，加進 v11 以後 hold 的 bp 卻比較少？

- 只看 Top50，Y2 也比 lgb_res 好：Top50 rank IC val 0.1090 對 0.1014、hold 0.1105 對 0.1066、post 0.0919 對 0.0855；
  Top50 多空（預測高於當天 Top50 中位數猜 1）hold 11.37 對 11.28 bp/日（幾乎一樣）。
- 把 v11 + Y2 對 v11 的 hold −1.00 拆開：選股部分（xsec）−0.65（t −1.63）、淨曝險部分（timing）−0.35（t −1.67）。
  v12 的 hold −1.05：xsec −0.93（t −2.29）、timing −0.12。
- Y2 單獨比 lgb_res 多 0.004 的 IC，放進 v11 以後只佔選股觀點的 1/6（LightGBM 部分的 1/3），整個選股觀點的 IC 幾乎沒變：
  全部股票 val 0.1140 → 0.1143、hold 0.1088 → 0.1090；Top50 hold 0.1139 → 0.1149。照 v11 A6 的換算
  （IC 每多 10⁻³ 換 0.03–0.06 bp/日），只值約 0.01–0.06 bp/日。
- 所以 hold 的 −1.00 不是「排序變差」，而是決策細節的差別（哪幾天、哪幾支剛好在猜 1／猜 0 的邊界上）；這種差別在不同期間
  正負不定（post +1.84），而且比期望的效果大很多（各期 bp 差的標準誤約 0.2–0.8 bp/日）。
