# v12：用實驗檢驗「ranking objective 沒有帶進新資訊」的解讀，並找 v12 的選股成員（事先寫好的規則，2026-10-26 18:30，任何新成績算出來之前）

使用者的要求：v11 第 9 節的解讀「lgb_res 本來就是『有沒有贏過當天平均』的加權二元分類，本身已經是同一天內的排序學習；
換成 lambdarank 只是換了損失函數，沒有帶進新資訊；十分位 label 還把報酬大小的資訊丟掉了」要用實驗檢驗，並弄成 v12。
v9、v10、v11 的檔案都不改；程式 `v12\research\v12_*.py`，結果 `v12\results\`，預測 `v12\cache\screen\`。
到這個時間為止，只有用合成資料核對自訂損失的梯度、量過訓練速度，沒有算過任何新模型的成績。

## 1. 要檢驗的說法

- **C1**：lgb_res（label = 贏過當天平均、權重 = min(|超額報酬|, 5%) 的 binary）本身已經是同一天內的排序學習：
  用真正「同一天兩兩比較」的損失、同樣的資訊（報酬大小）訓練，不會比 lgb_res 好。
- **C2**：換損失函數本身沒有影響：同樣的 label 資訊，pointwise、pairwise、lambdarank 三種損失的結果差不多。
- **C3**：十分位 label 丟掉了報酬大小的資訊：同樣的損失，label 用報酬大小比用十分位好。
- **C4**（第 9 節另一句）：X5 的 early stopping 輪數不穩定，是因為驗證期的 NDCG 對輪數很不敏感。
- **對立的說法 H3**：lambdarank 最佳化的是 NDCG，NDCG 的位置折扣 1/log2(1 + 名次) 讓排在最前面的幾支權重最大：
  第 1、2 名互換的權重是第 50、51 名互換的約 430 倍、第 99、100 名的約 1,100 倍。我們的分數要的是整天的排序
  （猜 1、猜 0 的分界在中段，猜 0 的在後段），所以 X5 比較差可能是「這個損失函數的重點放錯地方」，而不是
  「換損失函數沒有用」。H3 成立的話，C2 就不成立。

## 2. 實驗設計：把「label 帶多少資訊」和「損失函數」分開

| label 的資訊 \ 損失 | pointwise | pairwise（沒有位置折扣） | lambdarank（NDCG） |
|---|---|---|---|
| 正負：1{resid_r > 0} | **Y1 lgb_sign**（binary，沒有權重） | | |
| 正負 + 大小權重 | lgb_res（v9 現有：binary，權重 min(\|resid_r\|, 5%)） | | |
| 十分位：同一天內 resid_r 的十分位 0–9 | **Y2 lgb_dec_l2**（L2 regression） | **Y4 lgb_dec_pw** | X5 lgb_rank（v11 第 9 節，已有） |
| 大小：clip(resid_r, −5%, 5%) | **Y3 lgb_size_l2**（L2 regression） | **Y5 lgb_size_pw** | **Y6 lgb_size_rank** |

- **pairwise**：同一天的每一對 (i, j)，label 較高的是 i，損失 w_ij · log(1 + exp(−(s_i − s_j)))，w_ij = |label_i − label_j|
  （Y4 是十分位差，Y5 是報酬差）；每天把 w 乘上同一個常數，讓「每支股票的 w 總和」平均 = 1（和 binary 的梯度同一個尺度）。
  這等於把 lambdarank 每一對的權重 |ΔNDCG| 換成 |Δlabel|，所以 **Y4 和 X5 只差在有沒有位置折扣**，Y5 和 Y6 也是。
  用 LightGBM 的自訂損失（numba 算梯度和 hessian，已用合成資料和直接計算、數值微分核對）。
- **Y6**：label 用 0.25% 一格的等級 round((clip(resid_r, ±5%) + 5%) / 0.25%) = 0–40，label_gain 線性 0, 1, …, 40
  （gain 和報酬成正比），其他和 X5 完全相同。
- **共同**：B 的 67 個 feature；learning rate 0.02、num_leaves 15、min_data_in_leaf 500、feature_fraction 0.8、
  bagging 0.8、lambda_l2 1（和 lgb_res 相同）。pointwise 以列 bagging（和 lgb_res 相同），pairwise、lambdarank 以天 bagging
  （和 X5 相同）。最多 1000 輪，用訓練期最後 120 天、各自的損失（binary logloss、L2、pairwise logloss、NDCG@100）
  early stopping（patience 100），再用全部訓練資料重訓到最佳輪數。seed 1–5、6 個年度 fold（每個 30 個模型），
  和 X1、X5 相同的 walk-forward。

## 3. 第一部分：檢驗解讀（只報告，不決定 v12）

指標：每個模型（5 個 seed 平均）每天的 rank IC（當天全部約 100 支，預測和盤中報酬的 Spearman）；期間 val 2022–2024、
hold 2025-01 到 2026-05、post 2026-06-01 到 10-22、全期。兩個模型的比較用每天 IC 的差：平均和 NW t（5 lags）。

判定（事先定好）：
- **A 比 B 好**：全期的差 > 0、t ≥ 2，而且 val、hold 的差都 > 0。**A 比 B 差**：反過來。
- **差不多**：全期的差絕對值 < 0.002 且 |t| < 2（IC 0.002 約等於 0.06–0.12 bp/日，v11 A6 節）。
- 其他：**不確定**。

各說法的判定：
- **C2 / H3**（同樣資訊、換損失）：十分位那一行 Y2、Y4、X5 兩兩比；大小那一行 Y3、Y5、Y6 兩兩比。
  - C2 成立：兩行各自的三個都兩兩「差不多」。C2 不成立：任何一對是「好／差」。其他：不確定。
  - H3 成立：Y4 比 X5 好，而且 Y5 比 Y6 好（只差位置折扣）；只有一對成立記為「部分成立」。
- **C3**（同樣損失、換資訊）：Y3 對 Y2、Y5 對 Y4、Y6 對 X5。
  - 成立：三對裡至少兩對「大小比十分位好」，而且沒有一對「差」。不成立：三對都是「差不多」或「差」。其他：不確定。
- **C1**：Y5（同一天兩兩比較、權重 = 報酬差，資訊和 lgb_res 相同）對 lgb_res。
  - 成立：Y5 不比 lgb_res 好（差不多、差，或不確定但全期點估計 ≤ 0）。不成立：Y5 比 lgb_res 好。
    其他（不確定且點估計 > 0）：不確定。
  - 另外報告 Y3 對 lgb_res（L2 的 pointwise 在數學上就是同一天兩兩比較的 L2 損失，第 5 節）、Y1 對 lgb_res（大小權重的價值）。
- **C4**：6 個 fold 各用 seed 1，X5 和 lgb_res 在「訓練期去掉最後 120 天」上各訓練 1000 輪、不 early stop，
  記錄驗證期 120 天每一輪的 NDCG@100（X5），和第 10、25、50、100、200、300、500、750、1000 輪的驗證期 IC（兩個都記）。
  - 成立：至少 4 個 fold，X5 的 NDCG 在第 10–1000 輪的最大減最小 < 2 × 標準誤
    （標準誤 = 最高那一輪每天 NDCG 的標準差 / √120）。不成立：至少 4 個 fold ≥ 2 × 標準誤。其他：不確定。
- 只報告：每個模型的 IC 表；和 lgb_res 的相關（當天去平均後的預測），對照雜訊上限（lgb_res 兩組獨立的 5 個 seed：
  v11 第一部分的 seed 6–10 對 11–15 的相關）；預測排前 10%、後 10% 的平均超額報酬；前半段（預測最高的 50 支）內、
  後半段內的 IC（H3 預測 lambdarank 前段相對好、後段相對差）；early stopping 輪數。

## 4. 第二部分：v12 的選股成員（使用者的規則，和 PREREG_v11b、v11e 相同）

- 候選：Y1–Y6 各自加進 v11 選股觀點的 LightGBM 部分：(lgb_res + X1 + Y) / 3（Y 每天先去平均、縮放成 lgb_res 當天的標準差，
  和 X5 相同）。其他照 v11（T2、T3、w_T 0.5、λ 0.75）。
1. **入選：v11 + Y 對 v11 的 val（2022–2024）AR 差 > 0。**
2. **合併與檢驗：入選的全部一起加**（LightGBM 部分 = lgb_res、X1 和入選的 Y 的平均）**= v12；v12 對 v11 的 hold
   （2025-01 到 2026-05）和 post（2026-06-01 到 10-22）差都 > 0** → v12 做成和 v9、v11 並行的每天程式；
   任一段 ≤ 0，或沒有候選入選 → 沒有 v12 的每天程式，v11 不變。
3. 只報告：全期、6/1–9/30、10 月、每日 sd、P(19 天 > 0)、v9 + Y 對 v9。

## 5. 數學上的根據（C1 的 L2 版本，證明寫在 README_v12）

同一天 n 支股票，分數 s_i、label y_i：Σ_{i<j} ((s_i − s_j) − (y_i − y_j))² = n · Σ_i ((s_i − s̄) − (y_i − ȳ))²。
resid_r 每天的平均是 0，所以 Y3 的 pointwise L2 = (同一天兩兩比較的 L2 損失) / n + n · s̄²：後一項只管當天分數的平均，
和排序無關。也就是說 L2 的 pointwise 本來就是 pairwise。Y3 對 Y5 是「兩種 pairwise 損失（平方對 logistic）」的比較。
