# reg_svm：需不需要 regularization、換成 SVM 會不會比較好（2026-11-04，只有研究，沒改任何每天的程式）

使用者的問題（11/4）：「幫我評估一下我需要 regularization 嗎，我是覺得資料量夠多；還有我將模型換成 SVM 會比較好嗎」。
看過時間估計後：「給我 exact 版，目前考慮將其弄成額外成員」。

- 第 0 節：結論。
- 第 1 節：exact RBF SVM 當額外的選股成員：怎麼跑、要多久、規則（`research\PREREG_svm.md`），以及 11/4 晚上在筆電跑完的結果（1.4 節：沒通過）。
- 第 2 節：regularization，包括理論（直觀 + 證明）、有效樣本數、拿掉／加強 regularization 重訓三個成員、訓練資料量 1/8 到全部的實驗。
- 第 3 節：SVM，包括理論（SVM 就是 hinge loss + L2；hinge loss 學不到機率）、linear、Nystroem 近似、exact 小樣本、速度、當額外成員的預覽。
- 第 4 節：檔案。

雲端重訓的成員都和 walk-forward 完全相同：年度 fold 2022–2026-05 + post，訓練窗 2020-03-02 到 fold 前一天，用訓練期最後 120 天選停止點，
再用整個訓練窗重訓。val 2022–2024、hold 2025-01–2026-05、post 2026-06 以後。成員的 seed 1–2（另外註明的除外）。

## 0. 結論

**Regularization 要。現在的設定大致在對的位置，不用再加強。**

- 三個成員的 regularization 全部拿掉時，mini v9 從 13.60 掉到 11.79 bp/日（−1.80，t −1.46；hold −4.08）。這裡的 mini v9 是大盤 mlp_raw_B9、選股 (mlp_res_xr9 + lgb_res) / 2，加上 v9 的除權息規則和對沖。
  全部拿掉指的是：MLP 不做 early stopping、沒有 dropout 和 weight decay；LightGBM 沒有 min_data_in_leaf、lambda_l2、bagging，也不做 early stopping。
- **傷害最大的是大盤 MLP**。只拿掉它的 regularization 就 −2.52（t −1.98），每日 sd 從 49 變 57。
  它和大盤的相關在訓練期是 0.72，樣本外只有 0.07。樣本外 log-loss 0.7635，比永遠猜 0.5 的 0.6931 還差。
- **選股 MLP**：IC 從 0.1047 掉到 0.0862（−18%）。關鍵是 early stopping：留著 early stopping、只拿掉 dropout 和 weight decay，IC 是 0.1040，幾乎沒差。
- **LightGBM**：IC 從 0.1038 掉到 0.1010（−3%），幾乎沒差，因為 learning rate 0.02、15 葉本身就很保守。換成 LightGBM 的預設參數則是 0.0941（−9%）。
- **再加強也沒有更好**：dropout 0.5、weight decay 0.1；7 葉、min_data_in_leaf 2000、lambda_l2 10。同樣用 seed 1 比，+0.49（t 0.95），在雜訊之內。

**「資料量夠多」只對 LightGBM 大致成立。**

- 訓練天數從 1/8 增加到全部，LightGBM 拿掉 regularization 的 IC 損失從 −0.019 縮到 −0.003，資料每多一倍損失大約減半。MLP 則是 −0.042 → −0.019，一直都很大。
- 要比的不是 row 數，而是 n × SNR 和參數個數的比（第 2.1 節）。這份資料的 SNR 約 0.01：選股 rank IC 約 0.10，可以解釋的變異約 1%。
- 同一天的報酬也互相相關。選股一天 100 支只相當於約 35 個獨立樣本；大盤的部分一天只有一個值，整個訓練窗也只有 1,520 個。

**SVM 不會讓你不需要 regularization。Exact 版本身是好成員，但加進去量不到分數的改善。**

- SVM 本身就是 hinge loss + L2 regularization，C 就是 regularization 的強度（第 3.1 節）。exact SVC 用 1 萬 row：C 10 的 IC 是 0.049，C 0.1 是 0.083。
- hinge loss 的理想解只有「機率在 0.5 的哪一邊」（第 3.2 節）。但 pbar 要的是機率本身，選股要的是同一天的排序。LightGBM、MLP 用的 log-loss，理想解就是機率本身。
- Linear SVM 的 IC 是 0.0964，和 logistic 的 0.0947 差不多；用它換掉 v9 的 LightGBM，每天少 0.69 bp（t −1.36）。全部換成 linear SVM 則少 2.07 bp（t −2.57）。
- 近似的 RBF SVM（Nystroem）IC 是 0.1024，C 0.1 時 0.1050，和 lgb_res 的 0.1050 相同，沒有比較好。用它換掉 LightGBM 是 −0.55（t −1.24）。
- 把近似版當 v11 的額外成員，照第 1 節的規則：val +0.15、hold −0.75、post +0.96，所以沒通過。整個選股觀點的 IC 從 0.1105 變成 0.1102，幾乎沒變。
- **Exact RBF SVM**（11/4 晚上在筆電跑完，兩個 fold 同時跑共 2.72 小時，第 1.4 節）：
  - 自己的 IC 0.1093，是選股成員裡最高的（lgb_res 0.1050，每天成對比 +0.0044，t 1.47），也比近似版明顯好（+0.0069，t 3.10）。
  - 當 v11 的額外成員：val +0.03、hold −0.69、post −0.30、全期 −0.20。照事先寫好的規則，val 入選、hold 和 post 不是正的，**沒通過**。
  - 和現有成員每天的相關 0.82–0.90，整個選股觀點的 IC 只從 0.1105 到 0.1111。事後試換掉 lgb_res 也是 −0.25 到 −0.05 bp/日。
  - v9、v11 不變，不寫每天的程式。每晚要多花約 1.5 小時重訓，換不到量得到的分數。

## 2. Regularization

### 2.1 為什麼「row 多」不等於「資料夠」

**定理 1。** 線性模型 y = x'β + ε，x ∈ R^p 標準化且 E[xx'] = I，ε ~ N(0, σ²) 獨立，先驗 β ~ N(0, τ²I)。
訊號變異 s² = Var(x'β)，SNR = s² / σ²。

- (a) 所有估計量 b(X, y) 裡，平均預測誤差 E[(x₀'β − x₀'b)²] 最小的是 ridge：b = argmin ‖y − Xb‖² + λ‖b‖²，λ = p / SNR。
  寫成每筆平均的目標（除以 n），λ/n = (p/n) / SNR。
- (b) 不做 regularization（OLS，n > p + 1）時，誤差 / 訊號 = (p / (n − p − 1)) / SNR ≈ (p/n) / SNR。

**直觀。** 每個係數的估計誤差大約是 σ²/n，真正的係數大小大約是 s²/p。當 n·SNR 比 p 小很多時，估出來的係數大多是雜訊，往 0 縮會比較準。
所以「資料夠不夠」要看 n × SNR 和參數個數 p 的比，不是只看 n。SNR 只有 0.01 時，15 萬 row 相當於 SNR 1 的問題的 1,500 row。

**證明 (a)。**

1. 後驗 p(β | X, y) ∝ exp(−‖y − Xβ‖² / (2σ²)) · exp(−‖β‖² / (2τ²))。
   指數 = −(1 / (2σ²)) [‖y − Xβ‖² + (σ²/τ²) ‖β‖²]，是 β 的負定二次式，所以後驗是常態，平均數 = 眾數 = 括號的最小值點，也就是 λ = σ²/τ² 的 ridge。
2. 對任何只依賴 (X, y) 的 b 和任何 x₀，令 μ = E[β | X, y]：
   E[(x₀'β − x₀'b)² | X, y] = E[(x₀'(β − μ))² | X, y] + (x₀'(μ − b))²。
   交叉項是 2 (x₀'(μ − b)) · E[x₀'(β − μ) | X, y] = 0。
   第一項和 b 無關，第二項 ≥ 0，而且 b = μ 時等於 0。再對 (X, y) 取期望，b = μ（ridge）的平均誤差最小。
3. s² = E[β' E[xx'] β] = E[‖β‖²] = pτ²，所以 λ = σ²/τ² = pσ²/s² = p / SNR。□

**證明 (b)。** b̂ − β = (X'X)⁻¹X'ε，所以 E[(x₀'(b̂ − β))² | X, x₀] = σ² x₀'(X'X)⁻¹x₀。對 x₀ 平均（E[x₀x₀'] = I）得到 σ² tr((X'X)⁻¹)。

- 大數法則：X'X / n → I，所以 tr((X'X)⁻¹) ≈ p / n，誤差 ≈ σ²p/n。
- 除以訊號 s² = SNR · σ²，就得到 (p/n) / SNR。
- x 是常態時，X'X ~ Wishart_p(n, I)，E[(X'X)⁻¹] = I / (n − p − 1)，可以得到精確式 p / (n − p − 1)。這是 inverse-Wishart 平均數的已知結果，這裡直接引用。□

**代入這份資料**（2026-06 fold 的訓練窗；SNR 由相關係數換算，SNR = ρ² / (1 − ρ²)）：

| 情境 | 參數個數 p | 有效樣本數 n | SNR | (p/n) / SNR | 意思 |
|---|---|---|---|---|---|
| 選股，線性，67 個 feature | 67 | 約 53,000（1,520 天 × 約 35） | 0.010（IC 0.10） | 0.13 | 幾乎不用 regularization |
| 選股，LightGBM（15 葉 × 約 230 棵） | 約 3,450 | 約 53,000 | 0.010 | 約 6.5 | 一定要（數量級） |
| 選股，MLP 96-64-32-1 | 8,321 | 約 53,000 | 0.010 | 約 16 | 一定要（數量級） |
| 大盤，線性，18 個「每天一個值」的 feature | 18 | 1,520 天 | 0.012（相關 0.11） | 約 1.0 | 連線性模型都要強 regularization |
| 大盤，MLP 68-64-32-1 | 6,529 | 1,520 天 | 0.012 | 約 350 | 只能靠 regularization |

LightGBM、MLP 的「有效參數」不等於參數個數，這兩行只代表數量級，但方向和第 2.4–2.6 節的實驗一致。

- 線性選股的 linear SVM，C 從 1e-4 到 1e-1，IC 都在 0.095–0.097；
- v8 的大盤 logistic regression 挑到 C 1e-5 到 1e-3，是非常強的 regularization；
- 大盤 MLP 拿掉 regularization 傷害最大。

### 2.2 有效樣本數：同一天的報酬互相相關

- 原始報酬（大盤觀點的 label）：同一天的 intraclass correlation 0.154，一天 100 支只相當於 100 / (1 + 99 × 0.154) = 6.1 個獨立 row。
  大盤觀點要預測的大盤部分，每天只有一個值。
- 超額報酬（選股的 label）：當天平均已經減掉了。同一天、同一個產業群（4 群，每群約 25 支）的 intraclass correlation 0.079，
  一天 100 支約相當於 100 / (1 + 24 × 0.079) ≈ 35 個獨立 row。
- 訓練窗（2026-06 fold）有 151,949 row、1,520 天。選股的有效 row 約 5.3 萬，大盤約 1,520。

## 3. SVM

### 3.1 SVM 本身就是 regularization

**定理 2。** Soft-margin SVM 的寫法是：min ½‖w‖² + C Σᵢ ξᵢ，條件 yᵢ(w'xᵢ + b) ≥ 1 − ξᵢ、ξᵢ ≥ 0。它等價於

  min (1/n) Σᵢ max(0, 1 − yᵢ f(xᵢ)) + λ‖w‖²，λ = 1 / (2Cn)，f(x) = w'x + b。

**直觀。** 「margin 最大」就是 ‖w‖ 最小，也就是 L2 regularization。C 越大，regularization 越弱；C → ∞ 就是不做 regularization。
所以換成 SVM 不是不需要 regularization，而是 C 也要像 early stopping 一樣挑。
實驗：exact SVC 用 1 萬 row（fold 2026-01，gamma 0.25/67）。C 10 時 IC 0.049，C 1 時 0.074，C 0.1 時 0.083。

**證明。** 固定 (w, b)。ξᵢ 的條件是 ξᵢ ≥ 1 − yᵢf(xᵢ) 且 ξᵢ ≥ 0，目標對每個 ξᵢ 遞增，所以最佳 ξᵢ = max(0, 1 − yᵢf(xᵢ))。
代回去得到 min ½‖w‖² + C Σ max(0, 1 − yᵢf(xᵢ))。整個目標除以正數 Cn，最小值點不變，就得到上式。
Kernel 版把 ‖w‖² 換成 RKHS 的 ‖f‖²_H，證明相同。
SVC 的 sample weight 是把每筆的 C 換成 C·wᵢ，同理。□

### 3.2 hinge loss 學不到機率，只學到在 0.5 的哪一邊

**定理 3。** 固定 x，令 η = P(y = 1 | x)。

- log-loss L(q) = −η log q − (1 − η) log(1 − q)，唯一最小值在 q = η。
- hinge H(f) = η max(0, 1 − f) + (1 − η) max(0, 1 + f)，最小值在 f = sign(2η − 1)。η = ½ 時，[−1, 1] 都是最小值。

**直觀。** η = 0.51 和 η = 0.60 的股票，hinge 的目標都是 +1；它只在乎在 0.5 的哪一邊，不在乎多遠。
但我們的流程用的是 pbar 這個機率本身（w_T × (pbar − 0.5)）和同一天 100 支的排序。這兩樣 hinge 的理想解都沒有，log-loss 的理想解就是 η。
這份資料的訊號很弱：lgb_res 給的機率中間一半落在 0.46–0.56。在 0.5 的哪一邊很容易判斷錯，hinge 的理想解又把「離 0.5 多遠」的資訊丟掉。

**證明。**

- log-loss：L'(q) = −η/q + (1 − η)/(1 − q) = (q − η) / (q(1 − q))。q < η 時 < 0，q > η 時 > 0，所以唯一最小值是 q = η。
- hinge，f ∈ [−1, 1] 時：H(f) = η(1 − f) + (1 − η)(1 + f) = 1 + (1 − 2η) f，是一條直線。
  η > ½ 時最小值在 f = 1，值 2(1 − η)；η < ½ 時最小值在 f = −1，值 2η。
- hinge，f > 1 時：H(f) = (1 − η)(1 + f) ≥ 2(1 − η) = H(1)。f < −1 時：H(f) = η(1 − f) ≥ 2η = H(−1)。
  所以全域最小值在 f = sign(2η − 1)。□

**為什麼 SVM 在這裡還是能排序。** regularization 很強時，幾乎每一點都違反 margin（yᵢf(xᵢ) < 1），它們的對偶變數都卡在上界 αᵢ = C·wᵢ。
這時 f(x) = C Σᵢ wᵢ yᵢ K(xᵢ, x) + b，是「kernel 加權的 y 平均差」，同一天的排序和 C 無關。
實測：linear SVM 在 C 1e-5 時有 99.6% 的點違反 margin，exact SVC 有 92–94% 是 support vector；測試模式裡 C 0.01、0.03、0.1 的 val IC 完全相同，也是這個原因。
所以在這份資料上，SVM 實際上被逼成一個 kernel smoother，不是在「找 margin」。這也讓 exact SVM 的預測要算 n 次 kernel，訓練是 n² 以上的計算量。
