### 0.2 F-LOAM（程式已經放好，等你在筆電跑）

## 2. 設計（細節和規則在 `research\PREREG_v13.md`，訓練開始後、任何成績出來前寫好）

| 項目 | 設定 |
|---|---|
| label | 有沒有贏過當天 100 支的平均（y_resid），權重 min(\|超額報酬\|, 5%) |
| 輸入 | 每支股票最近 60 個交易日（D−60 .. D−1），每天 19 個 channel |
| 架構 | LSTM-R = v8 的 LSTM 原封不動（2 層、hidden 32）；CNN-R = 4 層 dilated 1D convolution（dilation 1、2、4、8，看 31 天） |
| 訓練 | 和 v8 的序列成員相同（AdamW、batch 1024、最後 120 天早停後重訓），只把 epoch 上限 10 → 30、patience 2 → 3 |
| walk-forward | 6 個 fold，訓練窗 2020-03-02 到 fold 前一天，seed 1–5 平均 |
| 判定 | 當選股觀點的新 family：p_e = c((MLP + LightGBM + 候選) / 3)；v11 + 候選 − v11：val > 0 入選；入選的合起來 hold、post 都 > 0 才通過 |

19 個 channel：

- 逐日 14 個（用訓練窗的 tfmodel.Scaler 標準化）：
  - K 線：intra = log(收/開)、gap = log(開/前收)、upper = log(高/max(開,收))、lower = log(min(開,收)/低)
  - 量：成交量、筆數、每筆股數各自除以 20 日平均（log）
  - 籌碼：外資、投信、自營商自行買賣、自營商避險的買賣超 / 20 日均量；外資持股比率的變化
  - 大盤：mkt = 當天 100 支 intra 的平均；rel = intra − mkt
- 視窗 5 個（Jiang-Kelly-Xiu 的 image scaling）：開、高、低、收用「視窗內最低的低、最高的高」縮成 0–1；成交量除以視窗內最大量。
- 刻意不放 B 的多日摘要（ret20、RSI、intra_bias_250 等）、美股、產業代號：模型只能自己從序列學。

檢查：

- 逐日 channel 在同一 row 和 B 的對應 feature 完全相同（intra 和 intraday_ret、gap、foreign_net、vol_ratio 等，最大差 0），
  所以 row D 放的確實是 D−1 的資料，60 天視窗全部是 09:00 前已知。
- leak check：把 D 之後的資料全部換成雜訊、或把資料截斷在 D，D 的預測完全相同（LSTM、CNN 都是差 0）。
- 重建的 v9、v11、W0 和公布的數字逐位相同（val / hold / post / 全期）。
- 雲端（Linux、pandas 3.0.5）和你電腦的 VM（pandas 2.3.3）跑同一個判定程式，結果相同。

沒有測的：

- **大盤觀點**：v8 四種架構的 pbar 和大盤的相關都在 0.085–0.15，瓶頸是資訊不是架構；目前上傳的 W0 也不用大盤觀點（w_T 0）。
- **2D K 線圖 CNN**：Jiang-Kelly-Xiu 自己的比較顯示 1D 加 image scaling 不輸 2D；2D 版（64×60 像素、64–256 個 channel）在筆電 CPU 上一個 epoch 要幾個小時。

## 3. 理論（直觀 + 證明）

### 3.1 序列模型吃人工 feature 為什麼加不了東西

直觀：B 組的 feature 已經是過去序列的摘要。如果今天這一 row 已經把過去序列裡「對明天有用」的部分都摘要完了，
讓模型再看一次整段序列，最好的情況是學到一樣的東西；實際上要多估很多參數，雜訊只會變多。v8 的 LSTM-B 正是這樣。

**定理 1**：令 x = 今天的 feature、W = 過去的序列、y = 要預測的 label。如果給定 x 之後 y 和 W 獨立（y ⟂ W | x），
那麼對任何 loss ℓ，min_g E[ℓ(y, g(x, W))] = min_h E[ℓ(y, h(x))]：多看 W 不可能讓最好的預測變好。

證明：對任何 (x, W) 和任何預測值 a，E[ℓ(y, a) | x, W] = ∫ ℓ(y, a) dP(y | x, W) = ∫ ℓ(y, a) dP(y | x) = E[ℓ(y, a) | x]，
第二個等號就是條件獨立。所以在每個 (x, W) 上讓條件風險最小的 a 只和 x 有關，a*(x, W) = a*(x)。兩邊取期望：
min_g E[ℓ(y, g(x, W))] = E[min_a E[ℓ(y, a) | x, W]] = E[min_a E[ℓ(y, a) | x]] = min_h E[ℓ(y, h(x))]。∎

有限樣本時更糟：多出來的參數只增加估計誤差。最簡單的例子是 OLS：y = Xβ + ε，n 筆、p 個參數、Var(ε) = σ²I，
則 E‖X(β̂ − β)‖² = σ²p。證明：β̂ − β = (XᵀX)⁻¹Xᵀε，所以 X(β̂ − β) = Hε，H = X(XᵀX)⁻¹Xᵀ 是秩 p 的投影矩陣，
E‖Hε‖² = E[εᵀHε] = σ² tr(H) = σ²p。∎ 每多一個沒有資訊的參數，平均就多 σ²/n 的誤差。

反過來，**吃原始序列時 x 不在輸入裡**，定理 1 不再限制模型：它必須自己學出 x 或更好的東西。學不學得到，看資料量和 SNR（3.3 節），這就是 v13 測的。

### 3.2 加一個成員什麼時候會變好

直觀：新成員要有用，IC 高還不夠，還要和現在的訊號「不一樣」。和現在的訊號相關 ρ 的那一部分現在已經有了，新成員真正的貢獻是剩下的部分。

設定：同一天內把現在的選股觀點 x、候選 z、超額報酬 y 都標準化（平均 0、變異數 1）；IC_x = corr(x, y) = a、IC_z = corr(z, y) = b、corr(x, z) = ρ，|ρ| < 1。

**定理 2**：
(i) 混合 s_w = (1 − w)x + wz 在 w = 0 的導數是 d corr(s_w, y) / dw = b − ρa。所以**加一點點 z 會讓 IC 變高，若且唯若 IC_z > ρ·IC_x**。
(ii) 所有線性組合裡最高的 IC 是 R = √((a² + b² − 2ρab) / (1 − ρ²))，權重 ∝ (a − ρb, b − ρa)，z 的最佳比重 w* = (b − ρa) / ((a − ρb) + (b − ρa))。

證明：
(i) corr(s_w, y) = C(w) / √V(w)，其中 C(w) = Cov(s_w, y) = (1 − w)a + wb，V(w) = Var(s_w) = (1 − w)² + w² + 2ρw(1 − w)。
C(0) = a、C′(0) = b − a、V(0) = 1、V′(0) = −2 + 2ρ。在 w = 0，[C/√V]′ = C′ − C·V′/2 = (b − a) + a(1 − ρ) = b − ρa。
(ii) 令 u = (x, z)ᵀ、Σ = Cov(u) = [[1, ρ], [ρ, 1]]、c = Cov(u, y) = (a, b)ᵀ。任何權重 β 的 corr(βᵀu, y) = βᵀc / √(βᵀΣβ)。
把 βᵀc 寫成 (Σ^{1/2}β)ᵀ(Σ^{−1/2}c)，由 Cauchy–Schwarz，βᵀc ≤ √(βᵀΣβ) · √(cᵀΣ⁻¹c)，等號在 β ∝ Σ⁻¹c。
Σ⁻¹ = [[1, −ρ], [−ρ, 1]] / (1 − ρ²)，所以 Σ⁻¹c ∝ (a − ρb, b − ρa)，cᵀΣ⁻¹c = (a² − 2ρab + b²) / (1 − ρ²)。∎

怎麼用（判定程式 PART 1 的 two-signal diagnostics，用每天的排序相關平均，是近似值）：

- SVM（11/4）：IC_z 0.1093 是選股成員最高，但和 v11 選股觀點的相關 ρ = 0.885。最好的混合在 val 也只從 0.1140 到 0.1167（+2%），
  照 v11 的經驗（IC +10% 約 +0.3–0.5 bp/日）大約 +0.1 bp/日，量不出來。這就是 SVM「IC 最高卻沒通過」的原因。
- 所以新成員的關鍵是 ρ 低、IC 不要太低。吃原始序列的模型 ρ 會低很多（第 4 節），問題是 IC 夠不夠。

### 3.3 資料量和 SNR：為什麼一定要早停

直觀：選股的 SNR 約 0.01（rank IC 約 0.10），同一天的報酬又互相相關，一天 100 支只約等於 35 個獨立樣本（reg_svm 第 2 節）。
整個訓練窗約 5 萬個有效樣本，模型有 1.3–1.5 萬個參數，照 reg_svm 2.1 的尺度 (p/n) / SNR ≈ (15,000 / 52,000) / 0.01 ≈ 29，
和選股 MLP（約 16）同一個等級：一定 overfit 訓練期，只能靠早停。吃原始序列還要把一部分容量花在「學出 feature」，
文獻的成功例子（Qlib、Jiang-Kelly-Xiu）訓練樣本多一到兩個數量級。

### 3.4 這個規則有多靈敏

**定理 3**：沒有效果時（三段的平均差都對 0 對稱、互相獨立），一個候選通過的機率是 1/8；有效果 δ（bp/日）時，
通過的機率約 Φ(δ√n_val / σ_val) · Φ(δ√n_hold / σ_hold) · Φ(δ√n_post / σ_post)，σ 是那一段每天差的標準差、n 是天數。

證明：通過 = 三段的平均差都 > 0。三段的日子不重疊，每天的差只有很弱的自我相關，所以三個平均近似獨立。
沒有效果時每段的平均差對 0 對稱，P(> 0) = 1/2，三段相乘 1/8。有效果時由中央極限定理，第 k 段的平均差近似 N(δ, σ_k² / n_k)，
P(> 0) = Φ(δ√n_k / σ_k)，再相乘。∎

判定程式 PART 3 用實際的 σ 算出這個機率（第 4.5 節）。重點是：**這個規則主要擋掉會變差的改法，不是靈敏的偵測器**，
+0.5 bp/日的真實改善也只有約三成的機會通過。所以「沒通過」不能證明完全沒用，但「val 明確變差」就是明確的證據。

### 7.2 論文做法的三個問題（直觀 + 證明）

**(a) 收盤價的 R² 高，不代表能預測。**

直觀：股價每天只變動一點點，整段期間卻漲跌很多。「明天 = 今天」的誤差是一天的變動，而 R² 的分母是整段期間的變異，所以 R² 一定接近 1，
和「能不能預測明天往哪走」無關。

**定理 4**：p_t = p_{t−1} + ε_t（隨機漫步，ε 獨立、變異數 σ²），t = 1..n、p_0 = 0。「明天 = 今天」的 MSE 是 σ²，
而 E[Σ_t (p_t − p̄)²] = σ²(n² − 1)/6，所以 R² ≈ 1 − σ² / (σ²(n² − 1)/(6n)) = 1 − 6n/(n² − 1) ≈ 1 − 6/n。

證明：Σ_t (p_t − p̄)² = Σ_t p_t² − n p̄²。E[p_t²] = tσ²，所以 Σ_t E[p_t²] = σ² n(n + 1)/2。
p̄ = (1/n) Σ_t p_t = (1/n) Σ_i ε_i (n − i + 1)，所以 E[p̄²] = (σ²/n²) Σ_{k=1}^{n} k² = σ²(n + 1)(2n + 1)/(6n)。
相減：E[Σ_t (p_t − p̄)²] = σ²(n + 1)[n/2 − (2n + 1)/6] = σ²(n + 1)(n − 1)/6。∎

n ≈ 1,650 天時 1 − 6/n ≈ 0.996。我們的 Top50 中位數 0.997（`floam_checks.py` A1，50 支在 0.967–0.999），論文的 0.98–0.999 就在「明天 = 今天」的範圍裡。
換成報酬（比賽真正要的東西）：「明天的報酬 = 今天的報酬」R² 約 −1，「報酬 = 0」約 0。

**(b) 隨機切分加上用測試集調參，等於讓模型看到未來。**

直觀：時間序列隨機切 80/20 時，每個測試日的前一天、後一天多半都在訓練集裡。模型可以「從前後兩天猜中間」，這在真的預測時做不到。
再用測試集的 MSE 挑參數，測試集就不再是樣本外。

**定理 5**：同上的隨機漫步，用前後兩天的平均 (p_{t−1} + p_{t+1})/2 猜 p_t，誤差變異數是 σ²/2，只有「明天 = 今天」的一半。

證明：p_{t−1} = p_t − ε_t、p_{t+1} = p_t + ε_{t+1}，所以 (p_{t−1} + p_{t+1})/2 − p_t = (ε_{t+1} − ε_t)/2，變異數 (σ² + σ²)/4 = σ²/2。∎

我們的資料（A2）：內插的 MSE 0.000069，「明天 = 今天」0.000129，比例 0.53，和定理一致；R² 0.998。
Optuna 用測試集挑參數的高估，見 overfit 檢查的定理 3：挑 K 組最好的，高估最多 s√(2 ln K)。

**(c) 整段做 SVMD 會偷看未來。**

直觀：VMD 是在整段序列的頻譜上解出來的，第 t 天去噪後的值是「前後很多天」的加權平均，包括 t 之後的價格。
留下低頻的 IMF 等於做平滑，平滑後的走勢在第 t 天往上，常常是因為 t + 1 天以後真的漲了。

**定理 6**：把去噪近似成一個線性濾波 c̃_t = Σ_k h_k p_{t−k}（k < 0 的項是未來）。在定理 4 的隨機漫步下，
Cov(c̃_t − c̃_{t−1}, ε_{t+1}) = h_{−1} σ²。對稱的平滑濾波 h_{−1} = h_1 > 0，所以「去噪後走勢的變化」和下一天的報酬正相關；
只用過去的濾波（h_k = 0，k < 0）這個共變異數是 0。

證明：c̃_t − c̃_{t−1} = Σ_k h_k (p_{t−k} − p_{t−k−1}) = Σ_k h_k ε_{t−k}。ε 互相獨立，所以
Cov(Σ_k h_k ε_{t−k}, ε_{t+1}) 只剩 k = −1 那一項：h_{−1} σ²。∎

VMD 的中心頻率是從資料估的、IMF 的取捨也看資料，不是嚴格的線性濾波，但給定這些之後，重建就是頻域上的線性濾波，機制相同。
A3 量的就是這件事：同樣的 SVMD，整段做和只用 D−250 到 D−1 做，特徵和 D 的報酬的 rank IC 差多少。

另外，8 個輸入裡有 7 個是「股價 × 或 ÷ 一個變化很慢的數」（市值 = 股價 × 股數、PE = 股價 / EPS 等）。
論文沒寫預測幾天後；如果是用同一天的輸入預測同一天的收盤價，答案就已經在輸入裡了。這是可能性，論文沒有寫清楚，沒辦法確認。
