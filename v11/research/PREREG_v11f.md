# v11 第三部分：把 10/27 的兩個問題做成規則來測（事先寫好的規則，2026-10-27 23:00，任何 F1、F2 的成績算出來之前）

使用者的問題：「10/27 的 AR 差，這要如何解決」，回答「也行」（測）。10/27 的診斷在 `results\rerun_1027_us\README.txt`：
主因是開高走低（上傳的 W0 設定 timing −25.75、xsec −44.05 bp），美股少兩晚只差約 4 bp，v11 預設的 T2 用了 10/22 的舊夜盤。
這裡把兩個可能的改法事先寫成規則，用 v11 第二部分同一份 walk-forward（2022-01 到 2026-10-22，1,164 天）測。
v9、v11 現有的檔案都不改；程式 `research\v11f_eval.py`，結果 `results\v11f_eval.txt`。

## 1. 候選

- **F1 休市後不用 T2**：預測日 D 和前一個交易日之間，只要有任何一個週一到週五台股沒開盤（國定假日、颱風假），
  D 的 T2 夜盤反轉這一項 = 0（當成夜盤缺值；PREREG_v11b 的 T2 定義裡，缺值本來就是 0）。一般的週一（中間只有週六、週日）不算。
  理由：TAIFEX 放假時沒有夜盤，FinMind 把放假前那一盤標成假期後的交易日；那一盤沒涵蓋假期中的美股和其他市場
  （10/27 用的是 10/22 15:00 到 10/23 05:00 那一盤，之後美股又交易了兩晚）。
  walk-forward 期間受影響的日子（只數日曆，還沒看成績）：val 28 天、hold 16 天、post 4 天，共 48 天。
  只影響 w_T > 0 的設定（w_T = 0 時同一天的 pbar 是常數，T2 本來就沒有作用）。
- **F2 Top50 每天固定一半猜 1**：每天 Top50 裡，除權息規則（當天、前一天、後一天、後兩天）的股票照舊猜 0；
  其他股票依 v11 的選股分數（p_e，含 X1）排序，分數最高的 floor(n/2) 支猜 1（n = 當天 Top50 的支數，通常 50 → 25 支），
  其餘猜 0（除權息規則的股票算在猜 0 裡）。所以淨曝險 = 0、timing = 0。除權息以外不到 floor(n/2) 支時，全部猜 1。
  不做 beta 對沖、不加 T3（兩者都是在調淨曝險）。w_T、T2 不影響同一天的排序。

## 2. 怎麼比

- 設定：v11 預設（w_T 0.5、λ 0.75、T2 0.5、T3 5 支、X1）；W0 = 10/27 上傳的設定（v11、w_T 0、λ 0.5，其他同 v11）；v9。
- F1：v11 預設加 F1，對 v11 預設的每日成對差（只有受影響的 48 天不是 0）。
- F2：對 W0、對 v11 預設的每日成對差。
- 期間：val 2022–2024、hold 2025-01 到 2026-05、post 2026-06-01 到 2026-10-22；t 用 Newey–West（5 lags）。
- 也報告（不參與決定）：全期、6/1–9/30、10 月、每日 sd、最差 1% 和 5% 的日子平均、P(19 天 > 0)、P(19 天 > 20)、
  平均 / sd、timing、xsec；10/27（live，用上線程式重算）只當資訊。

## 3. 規則

1. **F1**：48 個受影響的日子合起來，F1 − v11 預設的平均 **> 0** → 加進 v11 每天的程式（預設打開，`--no-f1` 可以關掉）；
   ≤ 0 → 不加，v11 不變。只看受影響的日子、不分三段，因為 F1 是「資料是否過期」的修正，不是新的訊號，而且 post 只有 4 天；
   分段只報告。
2. **F2**：它是控制風險的選項，不期待平均變高。不管結果，都做成 `train_and_predict_v11.py --balanced`（預設關，用不用由使用者決定）。
   **只有在 val、hold、post 三段的 AR 都 ≥ W0 時，才建議用 F2 取代 W0 當作低風險的上傳設定**；
   否則照報告的平均和波動自己選（和 v11 第 6、7 節、11/23 的風險決定同一類的選擇）。

## 4. 誠實說明

- 10/27 是讓我們想到這兩個改法的那一天，不能當證據，只報告。
- F1 的預期效果很小：T2 對 v9 的效果本來只有 val +0.14、hold −0.17、post +3.19 bp/日，48 天只佔 1,164 天的 4%。
- F2 和 v11 第 6、7 節的 w_T 0 是同一類的取捨（平均對波動）；這些期間都看過很多次，乾淨的只有 10/28 以後的 live。
